# 物料 brief 先行

## 为什么

三年的物料需求其实没变过：去 AI 味、不要剪影、几何或粉色或战术感、留二维码位。每次都直接出图，就会把同一批坑再踩一遍——因为约束从来没写下来。

## 先写 brief（四行，缺一行不出图）

1. **尺寸与入口**：抖音组图 1080×1440 / 竖屏视频封面 1080×1920 / 打印 A3 / 课程作业。
2. **必须出现**：主标题原文（含字数上限，例如 ≤20 字）、机构名或落款、二维码位、日期与地点。
3. **禁止出现**：剪影、刻板符号（水墨、龙、太极圆）、无关元素（桌游、美女）、AI 感光效。
4. **风格锚点（必须可检查）**：现代几何 / 低饱和军绿 / 档案纸张 / 粉色 + 传统占卜话术 / 黑白粗描边；给 1 张参考图，或写 3 个具体项——不要写「高级感」。

## 再画层级图（文字就够）

`主标题 > 副标题 > 一条信息 > 落款/二维码位`。层级定完再生成；生成之后只允许调这四层的大小与位置，不允许加新元素。

## 版权与不可控项

- 没有授权图时不要找替代图，改成排版型封面（标题哈希 / 字重 / 色块），把版权约束变成生成规则。
- 生成器画中文一定出错，标题一律后期排版，不让模型在画面里画字。

## 反例

- 只丢一句「收敛一下」→ 没有下文（039）。
- 连喊「不要刻板印象 / 不要剪影 / 纯几何」→ 说明前三版全踩了（048）。
- 背面「太杂太乱需收束」→ 有概念不等于所有概念都要画出来。

## 交付

文件名带尺寸与版本（`招新_1080x1440_v3.png`）；旁边留一份 md，写 brief 四行 + 最终图 + 下次可复用的风格锚点。
