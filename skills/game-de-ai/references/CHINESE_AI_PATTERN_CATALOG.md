# CHINESE_AI_PATTERN_CATALOG — 中文 AI 文案模式库

**用途**：识别和修改中文游戏文案里的 AI 写作习惯。
**总则（最重要）**：这是一份**识别线索**，不是禁词表。单独出现一个连接词、一处排比、一个破折号，都不构成问题；只有当它损害了**具体场景、人物声音、信息密度或阅读节奏**时才改。反过来，机械删词、把每句都改成短句口语，会造出第二种模板——见 §7。

用法：先按 `GAME_COPY_TYPES.md` 判定文字类型，再用本表逐条扫；每条只回答三件事：**出现了吗 / 它伤了什么 / 改哪一处**。

## 1. 内容问题（P01–P08）

| # | 现象 | 识别信号 | 改法 |
|---|---|---|---|
| P01 | 空洞宏大叙事 | 出现「时代／洪流／命运／史诗／洪炉」，但没有一个人、一个日期、一个地点 | 换成此刻正在发生的具体事：谁在哪做了什么 |
| P02 | 强行拔高普通事件 | 一件小事后面接「这，就是…的开始」 | 删掉最后一句；让事件自己停在那里 |
| P03 | 无内容情绪渲染 | 形容词 ≥3 个连用（「孤独、冰冷而漫长的」） | 只留能拍出来的那一个，其余删 |
| P04 | 无事实支撑的评价 | 「深受喜爱」「广受好评」「令人难忘」 | 改成事实：排队几人、开了几年、谁说过一句什么 |
| P05 | 模板化总结与展望 | 段落末「未来，还将…」「让我们拭目以待」 | 删。游戏文案不需要展望 |
| P06 | 反复解释已知信息 | 玩家刚做完 A，提示又说「你刚才完成了 A」 | 只说新增信息（结果、代价、下一步） |
| P07 | 万事皆有深意 | 每件物品、每个选择都被解释出意义 | 允许 30% 的道具就是道具：一句话说明它是什么 |
| P08 | 因果强行闭环 | 「正因为…所以…」出现在不需要解释的地方 | 保留并列，不必给每件事安排理由 |

## 2. 语言问题（P09–P22）

| # | 现象 | 识别信号 | 改法 |
|---|---|---|---|
| P09 | 高频连接词 | 一段里「然而／因此／此外／同时／值得一提的是」≥2 | 删连接词，靠语序承接；真正的转折只留一个 |
| P10 | 抽象词堆积 | 「机制／维度／层面／逻辑／体系／生态」在玩家话里出现 | 换成玩家会用的词：规则、局面、做法、家底 |
| P11 | 过度正式 | 「请」「予以」「进行」「提供」「相关」出现在按钮和提示里 | 按钮用动词，提示用短句：「已保存」「缺货」 |
| P12 | 句式雷同 | 连续 3 句以上同结构（都在「X 的 Y」或都是「把…」） | 至少打散一句：换主语、改语序、插一个短句 |
| P13 | 机械排比 | 三连排比出现两次以上；排比项字数整齐得像对齐过 | 只留两项，或让第三项明显不同长 |
| P14 | 反复对仗 | 「不是…而是…」「既…又…」「一边…一边…」密集 | 保留一处；其余改成直陈 |
| P15 | 伪金句收尾 | 每段最后一句都是短促、意味深长的结论句 | 把其中一半改成细节或动作，让它不"响" |
| P16 | 形容词过载 | 一句里形容词比名词多 | 形客比 ≤1:2；能落到动作上的形容改动作 |
| P17 | 同义替换癖 | 同一东西前后换着叫（茶杯／茶盏／杯子） | 统一一个叫法；换词只在故意区分时才用 |
| P18 | 破折号与省略号滥用 | 三百字里破折号 ≥3 或省略号 ≥3 | 破折号换逗号或句号；省略号每屏 ≤1 |
| P19 | 四字格堆叠 | 连续出现 ≥3 个四字成语／四字词 | 只留一个，其余写白话 |
| P20 | 万能动词 | 「进行／开展／实现／打造／赋能」 | 换成具体动词：记账、翻锅、签收、赶人 |
| P21 | 无主语抒情 | 「有一种…的感觉」「让人不禁…」 | 给主语，或直接写看见的东西 |
| P22 | 中英混排失衡 | 中文句里嵌英文术语当装饰（"氛围感 mood"） | 除非人物就是这行业的人，否则删 |

## 3. 角色与对话（P23–P32）

| # | 现象 | 识别信号 | 改法 |
|---|---|---|---|
| P23 | 全员同声 | 抽掉说话人名字后，分不出谁说的 | 给每人 2–3 个专属词/口头习惯（称呼、脏话、量词、句长） |
| P24 | 人人说完整句 | 没有半句、没有打断、没有答非所问 | 至少 1/3 的台词改成应答片段（「嗯。」「几点了？」「不等。」） |
| P25 | 对话解释场景 | 人物互相说「你看，那边的灯还亮着，说明有人在等我们」 | 把信息交给画面或旁白；让人说自己的事 |
| P26 | 每次发言都是观点 | 每个 NPC 都在讲道理、表立场 | 一半台词改成私事、抱怨、闲话、问价 |
| P27 | 语气无差异 | 老板、学生、城管、老人用同一种斯文 | 拉开句长（短/长）、称呼（你/您/喂）、礼貌程度 |
| P28 | 强行网络梗 | 「绷不住了」「绝绝子」「CPU 都烧了」 | 删。梗有保质期，且立刻显假 |
| P29 | 过度口语成主播腔 | 每句都「咱就是说」「真的会谢」 | 口语靠语序和省略，不靠流行词 |
| P30 | 人物知道太多 | 角色说出他不可能知道的信息 | 检查信息来源；见 `pov-guard` 的「来源：无」 |
| P31 | 台词承载教程 | 「按 E 可以拾取物品，这样你就能…」 | 教程归 UI；人物只说人话（「拿啊，愣着干嘛」） |
| P32 | 情绪直说 | 「他感到非常愤怒」「她很伤心」 | 换动作与生理细节：把碗放下、没抬头 |

|---|---|---|---|
| P33 | 按钮过正式/过长 | 「开始新的游戏旅程」 | 动词 + 宾语，≤4 字：「开始游戏」 |

## 5. 结构与整体（P41–P46）

| # | 现象 | 识别信号 | 改法 |
|---|---|---|---|
| P41 | 视觉密度平均 | 每段都差不多长、每屏都差不多满 | 拉长短差：关键处两句，铺陈处一行 |
| P42 | 全篇同一语气 | 菜单、提示、结局都是同一种「温吞叙述」 | 按类型换语气（见 COPY_TYPES）；结局可以最重 |
| P43 | 总结式收束 | 每个界面/每章都以一句总结结束 | 一半改成未完成感：一个动作、一个声音 |
| P44 | 缺少具体时间地点 | 全文没有日期、钟点、街道、天气 | 每个场景至少钉一个：几点、哪里、什么天气 |
| P45 | 情绪曲线平 | 从开头到结尾都是中等强度 | 设计一次「突然的短句」或「沉默」 |
| P46 | 跨项目同语言 | 《午夜餐厅》与《浮生牌》出现同一套比喻和句式 | 每项目独立 Voice Bible；写前先读它 |

### 5.1 判定顺序与强度（怎么用这 46 条，而不是背它）

**强度分级**（每条模式按此判，不是一律禁止）：

| 级别 | 含义 | 处置 |
|---|---|---|
| `hard` | 出现即改，几乎没有正当理由 | 直接改，不问 |
| `strong` | 默认改，但能说出理由就保留 | 保留时在复核单写一句理由 |
| `guideline` | 只是提醒，可能是风格选择 | 不改也不算错 |

对照：P01（无来源宽泛断言）、P09（连接词堆积）、P33（客服腔）≈ `hard`；P14（四字格）P30（口头禅）≈ `strong`——四字格对武侠/历史题材就是本行话，删成白话反而假；P43（总结式收束）≈ `guideline`——档案文体需要它。

**weak alone 不判**：单条弱信号不构成问题。
三条以上弱信号在同一屏/同一条相邻文本里同时出现，才升级为「这一处有 AI 腔」。
举例：单独一个「仿佛」不算；「仿佛 + 而 + 这正是 + 段末短句」三连出现就是 P41/P43 的合成信号。

**先判结构，再判表面**：同一段既有结构问题（P41 密度平均、P43 总结收束、P44 无时空）又有表面问题（连接词、四字格），先改结构。
只改表面会让你以为改好了——上游实测只清表面痕迹，质量只回升 1.6 点。

**覆盖率回执（硬要求）**：一次复核结束，必须回报
「共判 N 处 · hard 命中 a · strong 命中 b · guideline 命中 c · 判为不适用 d」。
没有这张回执＝没做复核。中文模式超过 20 条后，人（和模型）都会抽查三条就收工，只有逐条计数能治。

## 6. 可量化的文本指纹（自查用，不是评分器）

对 300–800 字的样本手工/脚本统计，落在下列区间外侧的信号要人工复看。
**密度口径**：`scripts/copy_scan.py` 把命中折算成「每千字命中数」，默认参考阈值 **5**（与上游 humanize 一致）；超过阈值不判对错，只说明这一批值得逐条看。
**误报白名单**：界面术语（「存档」「设置」「音量」）、人物设定内的口头禅、题材本行话（武侠的四字格、军事的术语）都不计入密度——报它们反而会把文本推向另一种腔。

| 指标 | 健康参考 | 过头信号 |
|---|---|---|
| 平均句长 | 12–22 字 | >28 字（文书腔）或 <8 字（每句都短＝伪金句） |
| 句长方差 | 明显（有 6 字句也有 40 字句） | 波动很小＝节奏平 |
| 连接词密度 | ≤1 个/100 字 | ≥2 个/100 字 |
| 四字格密度 | ≤1 个/80 字 | ≥1 个/30 字 |
| 形容词/名词比 | ≤0.5 | ≥0.9 |
| 破折号 | ≤1 个/200 字 | ≥1 个/60 字 |
| 段末「短句结论」 | ≤1/3 段落 | ≥1/2 段落 |
| 具体名词（可拍照物） | ≥1 个/段 | 0 个/段 |

**AI 检测器分数不能作为质量结论**；这些指标只用来找你该回头看的段落。

## 7. 反例：去 AI 味本身会变成新模板

以下做法和 AI 味等价，别做：

1. 见连接词就删，删到句子不成立。
2. 全篇改成短句，读起来像广告文案（「快。准。狠。」）。
3. 每段都塞一个脏话或方言词当「人味」。
4. 把所有比喻都删掉——具体不等于无修辞。
5. 把文言、方言、口语混着用，只为了「不像 AI」。
6. 用「我不装」「说人话」当开头，先声明再写作。

判断标准只有一条：**这句话，这个人在这个时刻，会不会这样说。** 答不出场景，就别改。
