# V2.1 必要史实复核（只核那些会影响转译的）

标记口径：**已证实**＝原始史料或实物＋可复核研究一致；**较可信**＝多数二手研究一致但缺一手；**有争议**＝两种以上说法并存；**暂无法确认**＝查不到可靠来源。

---

## 1. 糯米灰浆 vs 现代水泥（案例 09）

- **已证实**：糯米浆（支链淀粉）加入石灰砂浆后，检测到方解石含量 87.8–96.8%、残留支链淀粉、密度 1.81–2.20 g/cm³、抗压最高约 5.23 MPa；机理为支链淀粉抑制碳酸钙晶体长大、形成有机-无机致密网络。
- **已证实**：现代文物修复研究中，糯米灰浆被当作「与古建筑相容」的修复材料，而不是「比水泥更好的水泥」；现有研究多主张避免用水泥砂浆修补古建（强度与盐分不匹配），糯米灰浆的价值在**相容性**。
- **修正**：把两者写成「替代关系」是错的。它解决的是"新旧材料力学与化学相容"，不是"造更强的东西"。
- 来源：古建修复材料研究（含 CN106316227A 一类应用专利与灰浆配合比实验文献）。

## 2. 秦弩机：标准化／互换／署名（案例 10）

必须分开三件事，不能合成一句"秦代实现了标准化生产"：

- **署名（较可信）**：兵器上"物勒工名"的多级署名（相邦／工师／丞／工）有实物铭文支撑。
- **公差与规格（较可信）**：《睡虎地秦简·工律》"为器同物者，其小大、短长、广亦必等"是规格条文，属"要求"，不等于"批量互换的实测结果"。
- **真正互换（有争议）**：弩机部件可互换的**实测证据**（跨兵器同件互换试验）我没有找到可靠公开数据；只能写"设计上按同一规格制造，实物互换性未经独立验证"。
- 转译含义：可借的是「规格条文＋署名追责」这一对组合，**不能宣称秦代已完成可互换式量产**。

## 3. 人痘：生苗／熟苗与风险（案例 07）

- **已证实**：《医宗金鉴·幼科种痘心法要旨》列四法（痘衣、痘浆、旱苗、水苗），并明确排序"水苗为上，旱苗次之，痘衣多不应验，痘浆太涉残忍"。
- **较可信**：清代文献记"种痘死者百无一二"（约 1–2%），另一记载"种百儿之患，损伤四五个"（约 4–5%）被时人视为不可接受 → 存在**不同来源的死亡率区间**，不宜给单点数字。
- **不可做**：不能把它套成"现代疫苗风险分级"。人痘的风险来自**主动感染真天花**；现代减毒疫苗的风险机制不同。可借的是"分级选择＋选苗"这一**决策结构**，不是它的医学结论。

## 4. 糊名、誊录、初考、复考（案例 11）

- **已证实**：糊名（封弥）唐已有之，宋代制度化：992 年殿试、1008 年省试行糊名；誊录 1005 年殿试、1015 年省试、1037 年起全面推行。
- **已证实**：程序链——去卷首乡贯与姓名 → 编号 → 封弥 → 誊录院朱笔抄录（读官校对）→ 初考／复考分别定等 → 编排官核对两考异同 → 按字号调墨卷拆封。
- **注意**：不同年份、不同科目（殿试／省试／州试）推行时间不同，**不能跨时期拼接成一套"宋代统一制度"**；档案里已按年份标注，转译时只借"分离＋双评＋核对"的结构。

## 5. 青蒿素：古籍线索 vs 现代实验（案例 06）

- **已证实（古籍）**：葛洪《肘后备急方》"青蒿一握，以水二升渍，绞取汁，尽服之"——**渍、绞汁、生用**。
- **已证实（现代）**：1971 年改用乙醚低温提取，第 191 号样品对鼠疟抑制率 100%；1972 年分离出有效成分，1977 年公开，2015 年获诺贝尔生理学或医学奖。
- **较可信（机制）**：过氧桥在铁／血红素存在下断裂产自由基，对疟原虫产生杀伤；**遇热与长时间高温处理会破坏**。
- **必须区分**：古籍提供的是"低温、生用"的**操作性线索**；"是青蒿素、是过氧桥、是自由基机制"全部来自现代研究。写档案时不能把现代机制回填成古人已知。
- **采收期**：不同产地／采收期的有效成分含量差异有研究，但我没有拿到可引用的定量表 → **暂无法确认**（本档案不给数字）。

## 6. 坎儿井起源（案例 08）

- **已证实（构造与功能）**：竖井＋暗渠＋涝坝，重力自流，埋深减少蒸发；竖井间距常见 20–40 m（各地差异大）。
- **有争议（起源）**：汉代关中"井渠"说（王国维 1919 为代表）、波斯／中亚传播说、本土自生说并存，**至今无定论**。
- **转译含义**：机制（用坡度替代动力、用埋深替代密封）可用；**起源叙事不可当史实使用**。

## 7. 龙门账（案例 13）

- **已证实（结构）**：四柱＝进、缴、存、该；"进－缴＝存－该"为合龙门（差额相等）；票号另有流水账／分类账／现金账三账互核。
- **较可信（使用证据）**：清代票号账务与查账案例（如私吞后经查账暴露）支撑其实际运作。
- **有争议（创始人）**：傅山（傅青主）说与"富山"说并存，本档案不选边。
- **转译含义**：可借"两套口径必须同时成立"的勾稽结构；不要把它当"复式记账的起源"一句话打包。

## 8. 长信宫灯（案例 12）

- **已证实（实物与构造）**：通高约 48 cm、重约 15.85 kg；六个部件分铸后套合；宫女右臂为烟道、体内中空可盛水；灯盘可转、两片弧形瓦状灯罩可开合；头与右臂可拆卸以便清洗。
- **较可信（功能解释）**：烟尘经烟道进入体腔溶于水，减少室内烟尘；燃烧物推测为动物油脂。
- **暂无法确认**：净化效率的量化数据（如去除率），我没有可靠实测来源 → 档案里写"机制成立、效率未知"，不编数字。
- 来源：满城汉墓出土记录与博物馆／研究性介绍。

## 复核结论（一句话）

八项里，**三处需要改口径**（糯米灰浆不是替代水泥、秦弩互换性未验证、人痘风险不可套现代疫苗分级），**三处保留争议**（坎儿井起源、龙门账创始人、人痘源流年份），**两处补上未验证标记**（青蒿素采收期、宫灯净化效率）。档案原文不重写，差异以本文件为准并在方法卡里注明。
