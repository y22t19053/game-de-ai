## 一、五个指定线索的核验

| 线索 | 核验结果 | 处理 |
|---|---|---|
| **各顾各宝**（清代） | **未查到任何制度、契约或史料用此四字**。检索"各顾各"只得到俗语（"黄牛过河——各顾各"，《中国俗语大辞典》），含义是"各人只顾自己"，与"制度"相反。可能是方言记音、也可能是把某个民间规矩的名字记混了。 | **名称存疑，暂不作为案例**；不自行改成别的名字。若用户能提供出处（哪本书/哪个地区/什么场景），可重启核验。 |
| **神明庭**（明代） | 高度可能是**申明亭**之误记（"神明"与"申明"同音/近音）。申明亭确为明太祖洪武五年（1372）创设，与**旌善亭**成对；里推"老人"掌教化、剖断里中争讼小事；《教民榜》规定民间户婚田土斗殴小事"务要经由本管里甲老人理断"，不经里老而径告官者先杖六十。嘉靖淳安知县海瑞、隆庆万历间惠安知县叶春及曾重振其制；其制久行后出现亭宇不修、老人贪贿、颠倒是非等弊。 | 按**申明亭**立档，并在档案里注明"用户原始线索写作'神明庭'，疑为同名异写，本文不擅自改写用户用词"。 |
| **中世纪欧洲行会的集体发明与技术创新** | 成立但有学术争议：一派（如 Epstein 传统）认为行会通过学徒制与知识共享**促进**技术扩散；另一派强调行会**限制**竞争与创新。剑桥《经济史杂志》相关论文与 LSE 工作论文都记录了"共享的几何纪律/模块化尺寸"这类**集体技术知识**（如威尼斯造船以梁宽为模数推算龙骨长度）。 | 立档，但**把争议写进档案**，不采用单边结论。 |
| **罗马尿液税** | 成立。`vectigal urinae`，韦斯巴芗（Vespasian）时期征收；对象是**用尿做原料的洗衣工（fuller）与制革工**，不是全体市民；"pecunia non olet（钱不臭）"为其著名回应。学术上有一点重要保留：洗衣房可能主要用**自己的尿**，公共尿收集是否普遍仍有争议。 | 立档，保留该争议。 |
| **中世纪委身制** | 成立。拉丁文 `commendatio` / `patrocinium`（德文 Kommendation，意大利文 raccomandazione）。《Lex Ribuaria》§35 有 `homo ingenuus in obsequium alterius`（自由人投身他人役使），部分抄本标题作 `De eis ingenuis hominibus qui in obsequio se commendant`；法兰克贵族亦把子弟"commendare"给国王。 | 立档，限定为"自由人向保护人投附、换取保护与生计"的关系制度，不套现代"封建契约"概念。 |

## 三、为什么选这 5 项

选择标准不是"历史地位高"，而是"机制能被游戏用上，且史料够硬"。

| 案例 | 转译价值 | 史料硬度 |
|---|---|---|
| 申明亭 | 纠纷**先过滤再上交** + 善恶**双榜公示**——直接对应声誉系统、社区审判、UI 榜 | 高（制度条文 + 学术专著 + 弊病记录） |
| 常平仓 / 社仓（含主记与钥匙分置） | 共同储备 + 平准价格 + **双人管钥 + 账目上报**——对应库存经济与审计玩法 | 高（地方志勒石引文 + 成文规条） |
| 行会 | 集体技术知识 + 学徒阶梯 + **资格垄断**——对应技能树、公会、认证与排外 | 高（两篇学术文献，且保留争议） |
| 尿液税 | **把废物指定为税基**，且只向获利行业征收——对应资源循环、税收落点、道德争议 | 中高（学术文章 + 一条史料争议） |
| 委身制 | **依附换保护**、责任转移、可撤销的忠诚——对应阵营庇护、债务关系、背叛代价 | 中（一手法律条款 + 研究文献，缺具体契约样本） |

没选的：威尼斯兵工厂（很好，但与行会的"标准化/知识传递"重复，留作第二阶段）；保甲（互保株连有游戏价值，但史料未取全）；上计/勾检（审计价值高，但转译距离比常平仓远）。

## 四、向 100 例扩展的建议（不立刻做）

- **比例**：中国 ≥60（唐宋明清为主，先秦两汉补源流），其他文明 ≤40（地中海、西欧、南亚、伊斯兰、日本各若干）。
- **优先补的口子**：①审计类（上计、勾检、四柱清册）②互保类（保甲、什伍）③水权/公共资源（waterschap、分水碑）④凭证类（符券、票号、会票）⑤失败案例（一条鞭法后的摊派、牙行盘剥）——**失败案例至少占 20%**，否则只会抄"成功故事"。
- **每例产出一份 800–1200 字档案**，字段固定为 A 史实 / B 机制 / C 转译 / D 判断，且必须有一条"它在什么条件下失效"。
- 不做的事：不为凑数立档；不把同名异地制度合并；不把现代术语（"治理""契约社会"）当解释。

## 五、这一轮真正拿到了什么（诚实版）

**有证据的**：申明亭的"先调解后告官 + 善恶双榜"、社仓的"岁一敛散、收息什二、不欲者勿强"、钥匙与封记的双人控制、行会的模块化知识传递、尿税的征税对象只限获利行业、委身制的法律文本依据。
**仍是推测的**：这些机制搬进游戏后玩家是否觉得有意思（本轮只有设计推演，没有玩家测试）；"行会促进创新"仍是学术争议，不能写成定论。
**值得继续研究的**：申明亭（声誉与审判）、常平仓（库存与审计）、保甲（互保）、上计/勾检（凭证链）。
**应当淘汰的**：各顾各宝（查无实据）；"门下省封驳""历代考课"作为独立历史案例（已有现成机制，重复）。

**对创作能力的实际启发（一句话）**：这五个案例的价值不在"制度故事"，而在它们各自发明了一种**信息处理结构**——过滤、双账、资格、税基落点、依附契约。游戏里真正能用的，就是这五种结构。
