# 历史智慧与实用创新考古 · V2 研究范围（2026-11-15）

## 一、为什么扩范围

V1 只研究"制度"：纠纷、仓储、行会、税收、依附。它们解决的是**人与人之间的规则问题**。
但历史里还有另一大类东西——**在资源、知识、技术都极有限的条件下，把具体问题解决掉的办法**：一炉糖怎么脱色、一段城墙怎么粘住、一口井怎么打到一百米、一份卷子怎么让考官认不出笔迹。

这类东西对游戏更直接：它天然是**工序、材料、工具、信息与取舍**，而这些正是玩法与 UI 的素材。

**范围变了，目的没变**：仍是给 GAME DE-AI 找文案/视觉/UI/玩法/世界观/AI 协作的原材料，不是做历史兴趣项目。

## 二、八个方向（A–H）

| 方向 | 研究什么 | 对创作最可能的落点 |
|---|---|---|
| **A 医学·药物·经验知识** | 古方线索→现代验证、民间经验进正式知识、急救与公共卫生、剂型与提取 | 炼制/诊断玩法；"从线索到证据"的叙事结构 |
| **B 农业·食品·生存技术** | 育种、轮作、育苗移栽、储粮防腐、发酵腌制、节水、灾荒替代 | 生产循环、季节压力、失败惩罚 |
| **C 工程·建筑·材料** | 水利、桥梁、道路、结构（通风采光隔热防潮）、木石砖陶冶金、低成本替代、维修加固 | 场景与空间交互、可破坏/可维修系统 |
| **D 制造·工艺·工具** | 工序创新、模具夹具工装、标准件、技术传播、质检与追溯、流程优化、替代工艺 | 工位/流水线/质检 UI；"小工具改变生产方式" |
| **E 组织·制度·经济**（V1 五案在此） | 行会、公共资源、责任与监督、信用保险、税收激励、分布式执行 | 声誉、审计、契约、派系（已有档案） |
| **F 信息·教育·知识传播** | 目录索引分类、师徒与手册、印刷复制、跨区传播、防失传、隐性经验显性化 | 档案/线索管理、图鉴与检索、教学关 |
| **G 交通·物流·资源调度** | 驿站仓储运输、导航测量、长距贸易、灾时调度、路线优化、跨区协作 | 路线规划、补给、信息延迟 |
| **H 日常生活·低成本巧思** | 家用工具、清洁照明取暖通风、省料省能、废物再用、低成本维修 | 场景细节与音画；"小而有效"的机制 |

一个案例可属多方向。**E 不再是全部，只是其中一支。**

## 三、V1 五份档案的归档定位（不重写）

`cases/01_shenmingting.md`、`02_changping_she_cang.md`、`03_guilds.md`、`04_urine_tax.md`、`05_commendatio.md` 全部归入 **E 组织·制度·经济**，作为该方向的起点，**内容不动**。其中 02（仓窖与两本账）、03（资格与标准）、04（税点错位）在 V2 里会与新案例交叉引用，但不改写原文。

## 四、证据规则（比 V1 更严）

每个案例必须分清四种东西，混在一起就算不合格：

1. **史料记载**（原文说了什么）——注明出处与版本；
2. **现代实验/考古检测**（谁做的、测到什么数值）——给论文或机构；
3. **学术解释**（为什么有效，学界解释到什么程度）——有争议就写争议；
4. **我的推演**（能怎么用到游戏里）——标"推演"，不许伪装成结论。

另外三条硬规矩：
- **古代记载 ≠ 现代医学证据**。任何涉及药、毒、剂量、疗效的内容，只写"历史上怎么用、现代研究怎么看"，**绝不给现代医疗建议**。
- **同名异地不合并**（例如各地的"坎儿井"起源说互斥，就并列写）。
- **失败与淘汰案例照样收**，但必须说明失败原因（V2 候选池里至少留 5 个失败/被淘汰项）。

## 五、每份档案的固定结构

1 历史事实｜2 原始问题｜3 创新办法｜4 为什么有效（物理/化学/生物/工程/经济；解释不了就标"未知"）｜5 历史验证（用了没、重复没、有没有失败记录）｜6 现代转化（今天还能用吗、要什么条件、成本与限制）｜7 游戏创作转译（文案叙事 / 视觉 UI / 玩法交互 / 世界观场景 / AI 协作，至少给一个具体方案，含"玩家会感受到什么"与"引入后的新问题"）｜8 最终判断（可直接借鉴 / 需现代化改造 / 仅作灵感 / 有历史价值不宜转译 / 证据不足暂缓）。

## 六、边界（沿用，不放宽）

不新增部门、角色、审批流程；不因研究有趣就改 Skill；不改任何游戏工程；不把候选数量当成果；一个案例只写它真能支撑的部分。
