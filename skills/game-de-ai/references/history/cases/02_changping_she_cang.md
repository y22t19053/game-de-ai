# 案例 02 · 常平仓与社仓，以及「主记 · 钥匙」的双人控制（汉—宋—明清）

## A. 历史事实

- **常平仓**：汉宣帝时耿寿昌奏请边郡筑仓，"谷贱时增价而籴以利农，贵时减价而粜以利民"。唐宋续置，宋代诏两浙各置。
- **社仓 / 义仓**：朱熹乾道年间居崇安，遇大饥劝民发粟减价赈济，粟尽后贷粟六百斛，丰年民愿以粟偿官，遂立法"**岁一敛散，收息什二，不欲者勿强**"；小饥减半息、大饥全免。因"分贮民家，于守视出纳不便"，捐一年之息建仓专贮，号社仓，布其法于诸路。→ 一手性较强的**地方志勒石引文**（[识典古籍·仓储条](https://www.shidianguji.com/zh/mid-page/7577890009719488522)，E2）。
- **双人控制条文**：同一文献系统里另见家训/宗族规条："设**主记**一人，以会货泉谷粟出纳之数。凡谷匣收满，主记**封记**，不许擅开，违者量轻重议罚……**钥匙皆主记收**，遇开则渐次付之，支讫复还主记。"（[识典古籍条目](https://www.shidianguji.com/zh/mid-page/7576034218112499750)，E2；原书名待核）
- **徽州宗族的扩展经验**：宗族以契据、公匣、**轮房管理**、规约协调内部资产（《明清徽州宗族文书研究》，专著，E3）。
- **失效记录**：社仓后世常被强摊、息重、豪强侵占；常平仓官营亏空、出粜不均（散见明清记载，本轮**未逐条取原文**，标 E4）。

## B. 机制分析

- **问题**：粮价剧烈波动 + 小农无储备 + 地方无公共安全垫。
- **办法**：建立"公共仓 + 可预期的收放规则 + 利息与豁免"，并用**双人控制**（主记掌钥、封记、账目上报）防止管仓人私吞。
- **条件**：①有稳定补给（捐谷、罚谷、籴本）；②规则公开且不被地方官任意改；③有一批不贪的小吏/主记（最难）。
- **激励**：农民得低价粮与借贷；仓正得名与差遣；官府稳地方。
- **失效**：利息滚成债务、强制摊派、豪强把持仓权、账实不符且无人核。

## C. 创作转译

**核心借用**：①**平准**（低买高卖以平物价，而非单纯囤货）②**双钥**（两个角色各持一把，缺一不能开）③**账实分离**（账本与实物分别由不同人管，定期对账）。

1. **玩法**：经营类游戏加入"街区公共粮仓"（或共享食材库）。玩家可当仓正或主记：仓正管实物、玩家/另一 NPC 管钥匙与账。开仓需两人同时同意；账目每月上报"府衙"（系统日志）。天灾时玩家可放粮压价，也可囤积抬价——但会被另一把钥匙的人拒绝，除非玩家付出代价（贿赂/伪造账目→被发现则声誉崩）。
2. **UI/信息设计**：界面上做成**两本账**（实物进出账、银钱账）与**两把钥匙**的图示；一旦两账不平，界面出现红字并公开给街区。
3. **玩家感受**：每次想动手脚都得先对付另一半权限——**摩擦变成玩法**。
4. **为何比模板有意思**：常规经营游戏只做"库存数字 + 价格曲线"；这里把"谁能开仓"做成角色关系与审计问题。
5. **新问题**：两人制会拖慢节奏，需要给"紧急开仓"的例外（并让例外被记录、被追问）。

**判断：值得转译。** 证据等级 B（制度条文 E2 级，玩法未测）。
