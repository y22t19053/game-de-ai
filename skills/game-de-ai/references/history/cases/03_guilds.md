# 案例 03 · 中世纪行会：集体技术知识与资格垄断（11–16 世纪，西欧）

## A. 历史事实

- **名称**：guild / 行会（手工业行会 craft guild、商人行会 merchant guild）。
- **运行方式**：师傅（master）—帮工（journeyman）—学徒（apprentice）三级；行规管**质量标准、价格、工时、入行人数、宗教仪式与互助**；学徒期满需"代表作"（masterpiece）方可升师傅。
- **集体技术知识**：行会共享**模块化与几何纪律**的经验（尺寸以某一基准模数推算，如船体以梁宽推龙骨），技术通过学徒流动与行内示范扩散。相关研究：Cambridge《Journal of Economic History》行会与技术变革论文、LSE 经济史工作论文《Transferring Technical Knowledge》（**E2**，本轮只读摘要级）。
- **与威尼斯兵工厂的关系**：兵工厂约 1320 年起使用**标准化、可互换部件**，鼎盛约 1.6 万人、近每日一舰（[Guinness 记录页](https://guinnessworldrecords.de/world-records/100903-first-factory-to-use-standardized-parts), E3；管理史研究见 [Taylor & Francis 章节](https://www.taylorfrancis.com/chapters/edit/10.4324/9781003200055-4/history-management-stratigraphy-organizing-luca-zan), E3）——但**兵工厂是国家工场，不是行会**，二者不可混为一谈。
- **学术争议**：一方认为行会的学徒制与知识共享**促进**技术扩散与人力资本；另一方认为行会**限制竞争、压制创新、排斥外来者**。两方都有实证，**不能采用单边结论**。

## B. 机制分析

- **问题**：技术易失传、质量参差、外来低价竞争者冲击、行业无议价能力。
- **办法**：用"资格—标准—互助"三件套把行业变成**有门槛的共同体**：资格（学徒制）过滤人，标准（行规）保证质量，互助（行费/丧葬/济贫）抵御风险。
- **条件**：①城市自治与特许状；②市场有限、需求稳定（否则门槛会变成灾难）；③行会能执行排他（拒绝非会员开业）。
- **激励**：师傅得廉价劳力与市场保护；学徒得上升通道；城市得稳定质量与税收。
- **失效**：门槛变成**寻租**——提高入门费、限制学徒数、打压新技术（如织机）、排斥外来工匠；行业停滞时，保护变成集体衰退。

## C. 创作转译

**核心借用**：**资格（谁能做）与标准（做到什么程度）分开管理**，且两者都带排他性。

1. **玩法**：玩家在美食街开同业公会。公会能定"招牌菜标准"（做到 → 得认证标识、客单价上升），也能定"入会门槛"（收会费 / 限人数）。门槛越高，老会员越满意、新店越进不来；街区整体活力下降。玩家要在**短期保护**与**长期市场**之间做选择。
2. **UI**：资格证做成可贴在店门上的实物（有编号、有考核日期），标准写成"一页行规"（≤7 条），玩家能改，但改完所有会员都要重考。
3. **玩家感受**：每次抬高门槛，都能看见街上少了一家新店——**排他是有画面的**。
4. **为何比模板有意思**：常规"公会系统"只给 buff 与任务；这里把公会的**负面功能**（垄断、压制）也做成玩家可选的工具。
5. **新问题**：需要设计"新技术出现"事件（如新设备），让守旧的公会面临真实抉择，否则门槛系统只是数值。

**判断：有启发，值得转译为系统，但必须先处理"行会抑制创新"的争议**。证据等级 B。
