# 案例 05 · 中世纪委身制 commendatio / patrocinium（5–10 世纪，法兰克与意大利）

## A. 历史事实

- **名称**：拉丁 `commendatio`（投身、托付），亦称 `patrocinium`（庇护）；德文 Kommendation，意大利文 raccomandazione。
- **时间地点**：晚期罗马至加洛林时期的高卢、意大利；法兰克贵族把子弟"commendare"给国王，自由小农把自己托付给大领主。
- **一手条款**：《Lex Ribuaria》（《里普阿尔法》）§35 讨论 `homo ingenuus in obsequium alterius`（自由人投身他人役使），部分抄本标题作 `De eis ingenuis hominibus qui in obsequio se commendant`（关于那些投身于他人役使的自由人）。相关研究见慕尼黑大学学位论文与意大利学者对 commendatio 的专题论文（**E3**，本轮读到条款与研究摘要，未逐字校勘抄本）。
- **运行方式**：自由人（保留自由身份）在公开仪式中把手/自身交给保护人，承诺服务与服从；保护人承诺保护、供给生计、在纠纷中出面。**不是卖身为奴**，但实际自主权显著让渡。
- **参与者与利益**：小农（要安全，不要被豪强与盗匪吞掉）、领主（要人力与忠诚）、国王（要贵族的效忠，反过来也被要求保护）。
- **失效**：保护人变成勒索者（"保护费"式庇护）；托付可继承化、层层叠成封臣链；王权弱时，庇护关系成为私战的温床。

## B. 机制分析

- **问题**：中央无力提供安全，小农单户无法自保；需要一个**可执行的保护交易**。
- **办法**：把"保护"变成**有仪式的双边承诺**：我服从，你保护；违约有社会与宗教代价。
- **条件**：①暴力稀缺且地方化；②承诺可被见证（公开仪式、证人）；③保护人真有武力与司法影响力。
- **激励**：小农得安全；领主得人力与声望；国王得间接控制。
- **失效**：权力不对称 → 承诺不可执行；保护变成抽取；一旦可继承，依附固化，流动性消失。

## C. 创作转译

**核心借用**：**「保护—服从」的对价关系**，以及它的**可撤销性与不可撤销性**。

1. **玩法**：夜宵街有地头蛇收"保安费"。玩家可选：①拒绝（夜间被砸店风险上升）②向商会"托付"（交份子，换保安与纠纷调解，但接受商会的排班、抽成与站队要求）③与另一家结盟（互相照应，但对方出事要连带）。
2. **UI/信息设计**：不做抽象"好感度"，而做**一份契书**（谁保护谁、要什么、期限、违约条款），玩家每季可撕毁，但撕毁有可见后果（商会撤保、地头蛇找上门）。
3. **玩家感受**：玩家会算"自由 vs 安全"——**依附是有价格的**。
4. **为何比模板有意思**：常规阵营系统只给"加入 → 得 buff"；这里把**让渡自主权**本身做成代价（不能拒绝商会的差事、不能私下和解）。
5. **新问题**：容易变成"选最强的靠山"的最优解；需要让靠山**有内部政治**（交保护费的人之间也互相踩），并让玩家有机会成为"保护人"（角色反转）。

**判断：值得转译**，尤其适合"阵营—庇护—背叛"类叙事结构。证据等级 B（条款与研究为 E3，具体契约样本本轮未取）。
