# 案例 01 · 申明亭与旌善亭（明，1372 起）

## A. 历史事实

- **名称**：申明亭（读"申明"，非"神明"）；与**旌善亭**成对设置。用户原始线索写作"神明庭"，疑为同音异写，本文不改写用户用词。
- **时间地点**：明太祖洪武五年（1372）令天下里社各设，明清延续，嘉靖、隆庆间有地方官重振。
- **运行方式**：亭设于里社，推"里老人"（年高有德者，非职官）主之。亭内两榜：**恶人恶事书于申明亭，善人善事书于旌善亭**。民间户婚、田土、斗殴等小事，先由里老在亭中理断；《教民榜文》规定此类小事"务要经由本管里甲老人理断"，不经里老而径自告官者，先受越诉之罚（杖）。
- **参与者与利益**：里老人（声望/免役等好处）、里长甲首（执行）、州县官（把大量细故挡在衙门外）、乡民（低成本解决纠纷，但也可能被里老把持）。
- **失效与腐化**：亭宇久废不修；里老贪贿、颠倒是非、与衙役勾连；有地方官借亭榜羞辱异己。明代中后期多成具文，海瑞、叶春及等曾以知县之力重振。
- **史料等级**：制度概述见《明会典》《教民榜文》与方志远等学者的里老/乡里组织研究（**E3**）；具体运作与弊病散见地方志与文集（**E4**，具体州县样本本轮未逐条取）。

## B. 机制分析

- **要解决的问题**：州县官少、细故多，诉讼成本高且易激化；需要一个**低成本、在地、公开**的过滤层。
- **为什么这样办**：把"判断"和"公示"合在一处——亭既是法庭也是公告板；名誉（榜）替代刑罚（杖）。
- **依赖条件**：①熟人社会，声誉有效力；②里老人有实际威望且不被收买；③上级官府承认其裁决、不越级接案。
- **激励**：里老得声望与实务权；乡民省时间与诉讼费；官府减案牍。
- **失效机制**：声誉机制一旦被权力俘获（里老受贿、豪强借榜报私仇），公开性就从"约束"变成"武器"；且"不宜越诉"的硬门槛会阻断真正的冤情。

## C. 创作转译

**核心借用**：把"判决"拆成「过滤 → 公示 → 上诉」三段，且**公示本身是惩罚**。

1. **玩法**：玩家经营的夜宵街有邻里纠纷（噪音、抢客、倾倒废水）。玩家可先请街区"评理人"（NPC）公开评断，榜文贴在公告栏；当事人若不服，才可付高额代价告到官署。榜单会被全街区看到，影响客流与店家声望。
2. **UI/信息设计**：公告栏做成**两块**——"善榜"与"恶榜"，同一事件只在其中一块出现；玩家每次评断都在给某人记账。
3. **玩家感受**：判得公道会上榜得名声，判得偏心则看得见被冤枉者在榜单上被人指点——**代价可视化**。
4. **为何比模板有意思**：常规做法是"点击 → 弹出对话框 → 二选一 → 声望 +5"。这里把结果**挂在场景里**（墙上那张纸），且玩家的判词会长期影响 NPC 行为。
5. **新问题**：需要写大量判词与分歧反应；玩家可能学会"永远判给富人"的刷分策略——所以要给声誉反噬（恶榜反噬玩家自己的店铺）。

**判断：值得转译。** 证据等级 B（制度 A 级、玩家体验未测）。
