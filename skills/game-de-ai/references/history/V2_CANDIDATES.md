# V2 候选池：36 项初核 + 8 项选定

> 初核口径：**已核**＝名称/年代/基本事实有可查来源，且有具体做法（可写进档案）；**待核**＝有线索但细节或年代需查证，本轮不写档案；**存疑**＝名称或史实有争议，只记录不结论。
> 本轮**没有**把 36 项逐一读透——只有被选中的 8 项进入深档。这一列是"值不值得继续查"，不是研究成果。

## 三、选定 8 项（为什么是它们）

| 案例 | 方向归属 | 选它的理由 |
|---|---|---|
| 青蒿素（06） | A 医学 | 唯一一条"古籍一句话 → 低温提取 → 临床试验 → 全球用药"的完整链路，可拆出**假设—实验—失败—收敛**全过程 |
| 人痘接种（07） | A 医学 | 把"风险"当设计对象：减毒、选苗、隔离、死亡率的权衡 |
| 坎儿井（08） | C 工程 | 极端缺水下的工程解；且**起源有争议**，正好练习"不确定也照实写" |

| 弩机标准件+物勒工名（10） | D 制造 | 标准化+可追溯，两件事一次做完，直接对应质检与问责 UI |
| 糊名誊录（11） | F 信息 | 匿名化与去笔迹化，是"盲评"的历史原型，对 G4 盲排有直接参照 |
