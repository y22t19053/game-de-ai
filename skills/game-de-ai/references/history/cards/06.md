# 方法卡 06｜青蒿素：火候是变量

**证据等级：A 级**（古籍文本＋现代实验双重支撑；采收期定量数据暂无，见 V21_VERIFICATION §5）

1. **历史上具体做了什么**：葛洪记「青蒿一握，以水二升渍，绞取汁，尽服之」——冷水浸、绞汁、生用，不煎煮。1971 年改用乙醚低温提取，第 191 号样品对鼠疟抑制率 100%。
2. **有效机制 / 争议**：有效成分遇热与长时间高温会破坏，故"低温＋短时"是关键。**争议点**：现代机制（过氧桥、自由基）全部来自后来的研究，古人并不知道——写档案时必须把"线索"与"机制"分开。
3. **抽象后解决哪类创作问题**：一个看不见的工艺变量（温度/时长）决定成败，而玩家只能靠间接反馈判断它处于哪一档。
4. **可用位置**：烹饪/炼制的操作反馈、资源转化率、限时任务的"火候"提示、教学关的失败解释。
5. **原创转译方向**（不借古装）：
   - **三档火候条**：不看数字，只看汤色/气泡/声响三种现象，玩家从现象反推档位；
   - **过火不可逆**：越过某档后不可回退，只能被迫接受低一档产出（把"毁"变成可预期的代价，而不是随机惩罚）；
   - **双口径反馈**：口述反馈（NPC 说"太老了"）＋仪器反馈（温度计）互相印证，二者冲突时以现象为准。
6. **最容易的误用**：把它做成"卡时间条"的常规小游戏，只换皮成草药；或反过来把"低温提取"写成一句设定文案却没有任何可操作变量。
7. **一句话**：借的是「把不可见变量做成可读现象」，不是借青蒿。
