# 方法卡 09｜糯米灰浆：两种材料各干各的活

**证据等级：A 级（成分与力学）／修正：不是水泥替代品**

1. **历史上具体做了什么**：熟石灰＋糯米浆（支链淀粉）拌成灰浆砌筑；现代检测到方解石 87.8–96.8%、残留支链淀粉、抗压最高约 5.23 MPa。
2. **有效机制 / 争议**：支链淀粉抑制碳酸钙晶体长大，形成有机-无机致密网络，因而**与古砖石相容**（强度适中、不产生盐害）；今天主要用于**文物修复**，而不是替代结构水泥。
3. **抽象后解决哪类创作问题**：当"更强的材料"反而会毁掉已有结构时，怎么选"相容"而不是"更强"。
4. **可用位置**：修复/维护系统、装备改装、老建筑改造、材料相容性与副作用的表现。
5. **原创转译方向**：
   - **相容性优先的修理**：高等级材料修低级建筑会"开裂/返潮"，正确解是用匹配材料；
   - **配比小实验**：两种组分比例影响"强度/韧性/寿命"三条曲线，玩家自己找可接受区间；
   - **修复留下痕迹**：每次修补都在物件上留一条可见的接缝颜色差，强度不是唯一目标。
6. **最容易的误用**：写成"古代水泥，比现代水泥还强"；或在数值上把它做成纯上位材料。
7. **一句话**：借的是「相容优先于强度」，不是借糯米。
