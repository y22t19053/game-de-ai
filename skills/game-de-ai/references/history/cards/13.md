# 方法卡 13｜龙门账：两套口径必须同时成立

**证据等级：A 级（结构）／B 级（实务）／C 级（创始人争议）**

1. **历史上具体做了什么**：四柱＝进、缴、存、该；"进－缴＝存－该"为合龙门（差额相等）；票号另有流水账、分类账、现金账三账互核，查账由此暴露私吞。
2. **有效机制 / 争议**：不是"记账更详细"，而是**两套口径必须同时成立**，任何一边做假都会让等式崩掉。争议：创始人（傅山说／富山说）不选边。
3. **抽象后解决哪类创作问题**：当玩家可能"骗系统"或"系统可能骗玩家"时，怎么用结构让作假自动暴露。
4. **可用位置**：经营结算、库存、任务验收、玩家可篡改数据的系统、双人对局的仲裁。
5. **原创转译方向**：
   - **双册并列**：左册记"该发生的"（订单/应收），右册记"实际发生的"（实收/损耗），差额必须落到某个具名科目；
   - **合不上就停业**：差额无法解释时，不能进入下一回合，必须先冲销；
   - **三账互核**：同一笔交易在流水／分类／现金三处出现，任一处缺失即被标红（对应"初考/复考"式的独立校验）。
6. **最容易的误用**：做成"多几个数字的结算页"，差额自动抹平；或把四柱当成四种货币。
7. **一句话**：借的是「等式即校验」，不是借算盘。
