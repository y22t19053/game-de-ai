# 方法卡 11｜糊名誊录：让"看内容"这件事真的只看内容

**证据等级：A 级（程序）**

1. **历史上具体做了什么**：去卷首乡贯姓名 → 编号 → 封弥 → 誊录院朱笔抄录（读官校对）→ 初考／复考分别定等 → 编排官核对两考异同 → 按字号调墨卷拆封。糊名 992 殿试起、誊录 1005 殿试起，之后逐步推到省试并全面覆盖。
2. **有效机制 / 争议**：三道分离——**身份与内容**（糊名）、**笔迹与内容**（誊录）、**两次判断相互核对**（初考／复考）。争议：不同年份、不同层级考试推行时间不同，不可拼成一套统一制度。
3. **抽象后解决哪类创作问题**：当"判断被名气/文笔/身份污染"时，怎么把评审拆成可检查的工序。
4. **可用位置**：评审玩法（评卷/选秀/审稿）、盲选、拍卖鉴定、内部举报核查、AI 协作里的盲排。
5. **原创转译方向**：
   - **朱墨对照**：玩家先只看"朱卷"（重排格式、统一字体）判等级，再拆封看"墨卷"（原稿），系统记录两次判断差异；
   - **两考异同**：两位评审分别定等，差异超一档就必须写一句核对理由，否则不能拆封；
   - **拆封代价**：拆封会揭示身份，但会永久标记这份卷子"再也不能盲评"。
6. **最容易的误用**：只做"打码看内容"的皮，没有两次独立判断与差异核对；或把流程写成装饰性提示条。
7. **一句话**：借的是「三道分离＋双评核对」，不是借科举。
