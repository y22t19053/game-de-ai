# 方法卡 08｜坎儿井：用几何替代动力

**证据等级：A 级（构造）／D 级（起源，有争议）**

1. **历史上具体做了什么**：竖井（常见间距 20–40 m）＋暗渠＋涝坝，把地下水靠**坡度**自流引到绿洲；暗渠埋深以减少蒸发。
2. **有效机制 / 争议**：用重力与坡度替代泵与管道压力；用埋深替代密封。**争议**：起源有汉代井渠说／波斯传播说／本土说，学界无定论，不能当史实写进世界观。
3. **抽象后解决哪类创作问题**：预算/科技不足时，用**结构**而不是用**更强的东西**解决问题（"没有泵，就造坡"）。
4. **可用位置**：资源运输、基础设施建设、长期经营的地图布局、限制条件下的解法设计。
5. **原创转译方向**：
   - **坡度即预算**：修渠时每段坡度可调，坡度不足水到不了、过陡则冲毁，玩家用分段取舍代替一次性"升级"；
   - **竖井即检查点**：每隔一段必须留竖井，既是施工口，也是日后检修点（把"维护成本"提前写进布局）；
   - **埋深交易**：埋得深省蒸发但施工慢、检修难——三条变量互相咬。
6. **最容易的误用**：做成"点击修一条水渠"的常规放置；或把"坎儿井起源于波斯/汉代"写成世界观铁律。
7. **一句话**：借的是「以结构换资源」，不是借新疆风景。
