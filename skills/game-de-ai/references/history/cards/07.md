# 方法卡 07｜人痘：把"赌"变成"选"

**证据等级：A 级（方法与排序）／B 级（死亡率区间）**

1. **历史上具体做了什么**：《医宗金鉴》列四法——痘衣（穿患者衣物）、痘浆（痘疱浆液点鼻）、旱苗（痘痂阴干研粉吹鼻）、水苗（痘痂末水调点鼻），并排序"水苗为上，旱苗次之，痘衣多不应验，痘浆太涉残忍"；另有"选苗/熟苗"多代减毒的做法。
2. **有效机制 / 争议**：四种方法的**风险与可控性不同**，古人有明确排序并据此选择；"熟苗"是通过多代传代降低烈度。**争议**：死亡率记载不一（约 1–2% 与约 4–5% 两说），且**不能**套用现代疫苗的风险分级。
3. **抽象后解决哪类创作问题**：让玩家在"更高收益／更高风险"之间做**可比较**的选择，而不是抛硬币。
4. **可用位置**：事件抉择、经营风险、医疗/修理类系统、roguelike 的"赌一把"节点。
5. **原创转译方向**：
   - **风险四档并列**：同一目标给四种手段，成本/成功率/副作用各不同，界面必须并列展示而不是藏在 tooltip；
   - **熟苗机制**：玩家可把"高烈度素材"经 N 次低风险传代，变成稳定低风险素材（时间换安全）；
   - **失败也要有信息**：失败不弹"再来一次"，而是给出"这次是哪一档失效"的记录。
6. **最容易的误用**：把"人痘"当医疗建议或写成"古代疫苗真先进"；或者只做成功率数字，没有"选苗"这条可操作的降险路径。
7. **一句话**：借的是「分级选择＋降险路径」，不是借接种。
