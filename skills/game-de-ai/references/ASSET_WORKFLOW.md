# ASSET_WORKFLOW — 素材生产模块

> 目标：在艺术方向约束下，用最短路径产出一套**风格统一**的素材，并留下可复用的清单。
> 原则：先核心 3 张（能定义游戏气质的那几张），再补次要；宁可少而统一，不要多而散。

## 1. 选什么手段（先做选择，再动手）

| 素材类型 | 首选 | 次选 | 说明 |
| --- | --- | --- | --- |
| 界面背景/场景 | AI 图生成 | CSS 程序化 + 手绘叠加 | 生成后必须过统一层（§3） |
| 图标 | 自绘 SVG | AI 生成后重绘 | 统一笔压，形状故意不完全一致 |
| 纹理（纸/布/噪点） | CSS/SVG 程序化 | 扫描素材 | 程序化易统一、体积小 |
| 角色/人物 | AI 图（需固定 seed 与提示词模板） | 像素/剪影自绘 | 多角色必须同光照、同描边 |
| 食物/道具（经营题材） | AI 图 + 手工修边 | 照片改造 | 顶部光 + 油光高光必须统一 |
| 装饰元素（印章/贴纸/胶带） | 自绘 SVG | — | 这是「人类痕迹」的主要来源 |
| 字体 | 系统字体 / 可商用开源字体 | — | 记录许可 |

## 2. 素材清单先行

先写 `ASSET_MANIFEST.md` 的表格（名称 / 用途 / 尺寸 / 比例 / 格式 / 风格标签 / 来源 / 路径 / 状态），再开工。
规则：
- 每个素材有唯一 `id`，命名 `类型_用途_变体`（例：`bg_kitchen_night_v2.webp`）；
- 一个用途最多 2 个变体，先定稿再扩；
- 清单里「状态」只有四种：`待做 / 已生成 / 已统一 / 已采用`。

## 3. 风格统一（AI 素材必须过这四关）

1. **色阶**：统一黑位与色温（例：全部压到 `#0e0b08` 黑位，高光偏暖 8%）。
2. **颗粒**：叠同一张噪点（3–6%，`multiply`），强度全局一致。
3. **光照**：确认光源方向与色温，与界面一致；不一致的图重打光或裁掉。
4. **边缘**：统一处理（柔边/硬边/描边三选一），不要让一张图是抠图风、一张是插画风。

用 PIL 做批处理时，把参数写进 `ASSET_MANIFEST.md` 的「统一层」字段，下次直接复用。

## 4. AI 图片提示词结构（固定模板，减少漂移）

```
[题材与时代] + [媒介/画风] + [主体与动作] + [构图与镜头] + [光照与色温] + [材质细节] + [负向]
```
- 固定项（每次不变）：媒介、光照、色温、颗粒感、构图规则；
- 变化项：主体、动作、道具；
- 负向固定：`no text, no watermark, no ui, no border, no collage, no oversaturated neon, no plastic 3d render`；
- 批量时先用 1 张定基调，通过四关后再批量；
- 生成比例按用途定（背景 16:9 / 卡片 4:5 / 图标 1:1），不要后期硬裁。

## 5. 三筛（生成的图不必都用）

1. **缩到 15%**：剪影是否可辨？糊成一团 → 弃。
2. **100%**：细节有没有崩（手、字、对称物、边缘）？→ 修或弃。
3. **放进界面截图**：和已有素材并排是否同一世界？→ 弃或重打光。

## 6. SVG 自绘规范

- `viewBox` 必写；颜色优先 `currentColor`，需要多色时用 CSS 变量；
- 描边 1.5–2px，圆角 ≤2px（除非母题要求）；
- 手绘感：路径加 ±0.5px 抖动、端点故意不闭合 1px；
- 图标统一 24×24 网格、2px 安全边距；
- 装饰件（印章、胶带、笔迹）单独存 `decor_*`，方便复用。

## 7. CSS 程序化纹理配方（零文件、易统一）

```css
/* 纸纹 */ .paper { background-image:
  repeating-linear-gradient(0deg, rgba(0,0,0,.03) 0 1px, transparent 1px 3px),
  radial-gradient(circle at 30% 20%, rgba(255,255,255,.06), transparent 60%); }
/* 颗粒 */ .grain::after { content:""; position:absolute; inset:0; pointer-events:none;
  background:url("data:image/svg+xml,<svg xmlns='http://www.w3.org/2000/svg'><filter id='n'><feTurbulence baseFrequency='.8' numOctaves='3'/></filter><rect width='100%' height='100%' filter='url(%23n)' opacity='.35'/></svg>");
  mix-blend-mode:multiply; opacity:.25; }
/* 扫描线 */ .crt { background-image: repeating-linear-gradient(0deg, rgba(0,0,0,.18) 0 1px, transparent 1px 3px); }
```

## 8. 优先级与预算

- 第一轮只做：1 张主视觉（背景/场景）+ 1 套面板材质 + 6 个图标 + 1 个装饰件。
- 第二轮补：角色/道具、状态图标、动效帧。
- 第三轮才是：边框变体、加载图、成就图。
- 任何素材没进清单 = 不存在（防止做完找不到）。

## 9. 交付自检

- [ ] 清单里每个「已采用」素材都有路径和尺寸？
- [ ] 所有 AI 图是否都过过统一层（色阶/颗粒/光照/边缘）？
- [ ] 图标是否同一笔压、同一网格？
- [ ] 有没有一个素材在缩到 15% 时糊掉还在用？
- [ ] 字体许可是否记录？
- [ ] 一个用途是否 ≤2 个变体？
