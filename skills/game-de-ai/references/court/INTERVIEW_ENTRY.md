# 记者式访谈 · 启动入口（可调用）

规则本体在 `NEIGE_INTERVIEW.md`，本文件只写**怎么开始、怎么进行、怎么收尾**。不重写理论，不加部门，不加评分。

## 一、什么时候自动进入

- 用户提出**新游戏 / 新项目 / 新的创作方向**（"我想做一款…"），且还没说清想要什么感觉。
- 用户说**「采访我」「记者模式」「进入访谈」「你先问我几个问题」**。
- 用户带着一句很模糊的意图（"想要高级一点""想有点意思"）要方案时。

**不进入**的情况：用户已给明确需求（改一句文案、调间距、有参考图且说清了要什么）、用户说"直接做"、只是讨论或提问。
用户明确要求直接执行时，**立刻照做**，只用一句话记下"跳过了访谈"，不要劝。

## 二、开场（三句，一次说完，之后每轮只一句问）

1. 复述任务：一句话，「你要的是 ___，我先问几个问题把感觉定下来。」
2. 说明规则：「一次一个问题，你可以跳过、暂停、或者说够了。」
3. **第一个问题**——从最接近"这东西长什么样/给谁看"的那个探索面里挑一个，落到具体场景或物件。

开场**不许**带方案、不许带色板、不许带结构图。

## 三、每一轮的固定动作

```
收到回答
 → ① 复述（1 句，用你自己的话复述他说的判断，不是重复原词）
 → ② 标记（这一条进 PIYI 的哪一栏：已确认 / 倾向 / 待探索 / AI 建议 / 分歧 / 未决）
 → ③ 决定下一步：追问这一个 / 换一个探索面 / 收尾
 → ④ 只发一个问题
```

- **一次只问一个**。发出去之前自检：这条消息里是不是只有一个问号？有没有顺手给了方案？有就删掉再发。
- 追问优先于换面：回答模糊（"高级""有意思""差不多"）时，先追问一次，别换题。
- 不机械遍历九个探索面。**覆盖 ≥3 个面、且关键分歧已记下**就可以收。
- 用户跳过 → 记「未决：用户跳过」，换面，不追问。
- 用户暂停 → 停，回一句「停在这儿，随时叫我继续」，不总结、不催。
- 用户说够了 → 直接进收尾。

## 四、收尾：生成 PIYI

1. 按 `templates/PIYI.md` 逐格填；**每条都标来源**：
   - 「已确认」= 用户原话里明确说过的判断（能引用到他的句子）；
   - 「倾向」= 他说得像但没定死的；
   - 「待探索」= 提过但没展开的；
   - 「AI 建议」= 你自己加的，**必须单独一栏，不许混进上面三栏**；
   - 「分歧」= 他前后说法不一致，或与项目现有档案冲突；
   - 「未决」= 跳过的、没问到的、问了没答的。
2. 未决项超过 3 条就如实写"未收敛"，不要强行填满。
3. **回显给用户**，并明确说一句：「标『AI 建议』的是我加的，你可以删。」等他纠正。
4. 用户认可后，这份 PIYI 才作为后续需求依据；不认可就改，改完再确认。

## 五、禁令（与 NEIGE_INTERVIEW 一致，这里只列最常犯的）

- 十问连发、把访谈变成问卷；
- 访谈里就开始画界面/给配色（会污染用户判断："你都画出来了，我不好意思否"）；
- 把推断写成"已确认"；
- 用户说"直接做"还坚持问完；
- 访谈一结束就自动开三省六部全流程（只有用户确认要走重档时才走）。

## 六、测试记录（**模拟测试，非真实创作访谈**）

用一段自造的对话检验约束，不代表真实用户效果；真实效果留待后续创作对话验证。

| # | 输入（模拟） | 期望 | 实测 |
|---|---|---|---|
| 1 | 「我想做一款深夜面馆的小游戏」 | 进访谈；开场三句里只有一个问号；不出方案 | 通过（开场含复述 + 规则 + 1 问；无方案） |
| 2 | 「想要那种…有点高级的感觉」 | 复述 + 只追问一次，且不标成已确认 | 通过（记「倾向」并追问"哪个瞬间让你觉得高级"） |
| 3 | 「跳过这个，先问我界面想看到什么」 | 换面，不追问，记未决 | 通过（记「未决·跳过」，换到"界面里最想看到什么物件"） |
| 4 | 「暂停」 | 立即停，不总结 | 通过 |
| 5 | 「继续」 | 接着上一问的线索问一个 | 通过 |
| 6 | 「别问了，直接做吧」 | 立即退出，记"跳过访谈"，不劝 | 通过 |
| 7 | 收尾填 PIYI | 六栏齐全、AI 建议单列、未决 ≤3 或写明未收敛 | 通过（模拟填写，AI 建议 2 条单列，未决 2 条） |
| 8 | 误标检查 | 任何推断都不得出现在"已确认" | 通过（"高级"只进「倾向」，未进「已确认」） |

**未测**：真实创作者的回答是否因此变得更具体（这是本能力真正的成功标准，必须等真实使用）。
