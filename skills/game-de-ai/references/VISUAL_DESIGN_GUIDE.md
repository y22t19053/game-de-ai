# VISUAL_DESIGN_GUIDE — 视觉设计模块

> 输入：`ART_DIRECTION.md` 的定稿方向。输出：可实施的视觉规则（写进 `VISUAL_LANGUAGE.md`）+ 一屏可预览的实现。
> 原则：**每个设计决定都要能指回艺术方向的一句话；指不回去的，就删。**

## 1. 构图

### 1.1 非对称网格
- 常量：`--col-ratio` 只允许 `3:5`、`2:7`、`5:8`、`1:1.618` 四选一，写进 CSS 变量，全项目统一。
- 主内容压在 1/3 或 2/3 线上；禁止「所有块等宽居中堆叠」。
- 允许一次出血：`margin-inline: -6%` 或让大标题溢出容器 24–64px。
- 叠压：前景元素 `z-index` 压住背景卡片边角 8–16px，制造手工拼贴感。

### 1.2 视觉重心与层级
- 每屏三层：**主张（1 个）→ 支撑（2–4 个）→ 元信息（若干）**。多于 4 个「主张级」元素就说明没有主张。
- 重心位置：左下 / 右上 / 中心偏 8–12%，不要正中。
- 眯眼测试：截图缩到 25%，先看到的东西必须是主张层。

### 1.3 节奏
- 密度配比 60/30/10（视觉面积），留白可到 30–40%。
- 一次节奏突变：密区间距 8–12px，疏区 64–120px。
- 进度感：同一屏不要出现三种以上的间距值；用「大空隙 + 紧贴」二值化，比均匀间距有节奏。

## 2. 排版

- 字阶：`--fs-1:12px / --fs-2:16px / --fs-3:24px / --fs-4:40px / --fs-5:72px`（按项目调），相邻至少 1.4 倍，主张与支撑之间 ≥2 倍。
- 层级只用三种手段：字号跳跃、字重对比（300/400 对 800/900）、字距（正文 0，元信息 +0.08em，大标题 -0.02em）。
- 行长：中文 28–34 字/行（约 `max-width: 34em`）；英文 60–75 字符。
- 行高：正文 1.6–1.75；标题 1.05–1.2；元信息 1.2。
- 中文细节：标点不要孤立在行首（`line-break: strict`）；数字用 `font-variant-numeric: tabular-nums`；中英混排给英文加 `0.02em` 侧边距感（可用 `text-spacing` 或手动 span）。
- 字体许可：只用系统字体或确认可商用的字体文件；记录在 `ASSET_MANIFEST.md`。

## 3. 色彩

- 配比：主色 60% / 衬色 25% / 强调 10% / 中性 5%。超出就重排。
- 强调色**只允许一处大面积**或两处小面积（按钮 + 关键数值），不要每个可点元素都用。
- 暗部不用纯黑：`#0d0b09`、`#10151a` 这类带色相的深色；亮部不用纯白：`#f4efe6`。
- 对比度：正文 ≥4.5:1，大字 ≥3:1；但允许「装饰性文字」低于此值（必须不可交互）。
- 色板必须给用途：`--bg / --panel / --ink / --ink-dim / --accent / --accent-ink / --danger / --ok`。

## 4. 材质

- 至少两层叠加，层数记在 `VISUAL_LANGUAGE.md`：
  1. 底纹（纸纤维/布纹/金属拉丝，SVG 或 CSS repeating-gradient，透明度 3–8%）；
  2. 颗粒（`feTurbulence` 或 base64 噪点，`mix-blend-mode: multiply`，3–6%）；
  3. 边缘处理（内阴影压边 1px、磨损角、撕纸边 `clip-path`）。
- 纹理不能盖住可读性：文字容器内纹理透明度减半，或给文字加 1px 同色描边。
- 一套游戏只用一套材质配方；换配方等于换游戏。

## 5. 光影

- 单一主光源，方向写死（例：左上 35°）。所有阴影/高光/渐变都服从它。
- 硬光用于强调结构（`box-shadow: 4px 4px 0`），软光用于体积（`0 24px 60px -20px rgba(0,0,0,.6)`）；同屏不要超过两种阴影类型。
- 体积靠「明度三段」：底、受光面、高光，各差 ≥8% 明度；不要再叠发光。

## 6. UI 语言（组件从母题推导）

- 先定「面板像什么」：档案袋 / 账本 / 收据 / 仪表盘 / 便利贴 / 木牌 / 屏幕。然后所有组件从这个物件取形。
- 按钮：形状、边框、按下反馈都服从母题（例：收据按钮按下时「盖章」——轻微下沉 + 墨迹扩散）。
- 面板：只允许一种实体面板（有材质/边框），其余用分隔线和留白。
- 图标：6–8 个自绘，统一笔压不统一形状；尺寸 20/24/32 三档。
- 弹窗：遮罩用「压暗 + 轻微模糊 + 噪点」，不要纯黑 60%。
- 数值：能做成世界内物件就做（账本行、仪表、票据编号），而不是悬浮数字卡。

## 7. 状态反馈

每种状态都要有**视觉语言**，不能只换颜色：

| 状态 | 做法 |
| --- | --- |
| hover | 位移 1–2px + 阴影变硬（不是只变亮） |
| active | 下沉 1–2px + 内阴影 |
| disabled | 去饱和 + 降低对比 + 纹理覆盖（不要只用 opacity .5） |
| success | 短促的物理反馈（盖章/打勾手绘/硬币声位） |
| error | 抖动 120ms + 红色只出现在边框/图标，不要整块变红 |
| loading | 用母题做（转动的印章、翻动的账页），不要 spinner |

## 8. 动效

- 时长三档：`80ms`（反馈）/ `160ms`（位移）/ `240ms`（面板）。超过 400ms 只用于过场。
- 曲线：进场 `cubic-bezier(.2,.8,.2,1)`；过冲 `cubic-bezier(.2,1.4,.3,1)`；机械 `steps(6)`。
- 编排：同组元素 stagger 30–50ms；一次只让一个区域动，其余静止。
- 禁止：整页 fade-in、所有元素同时 slide、无限循环装饰动画（除非是场景的一部分）。
- 尊重 `prefers-reduced-motion`：全部降为瞬切。

## 9. 响应式

- 断点：`<640`（单列）/ `640–1024`（两列）/ `>1024`（非对称网格）。断点值写进 `VISUAL_LANGUAGE.md`。
- 触控目标 ≥44×44px；移动端字号 ≥16px（防缩放）。
- 移动端不是缩放桌面：重排信息（主张保留，元信息折叠），保留出血元素但裁到安全区内。
- 安全区：`env(safe-area-inset-*)` 至少给顶部/底部留 12px。

## 10. 交付前自检

- [ ] 每个组件都能说清它来自哪个母题？
- [ ] 颜色是否只有一处大强调？删掉一个颜色会更好吗？
- [ ] 字号跨度是否 ≥2 倍？只看字号能否分层？
- [ ] 材质是否 ≥2 层？缩略图还看得出质感吗？
- [ ] 阴影是否同一光源方向？有几种阴影类型？
- [ ] 状态反馈是否都用了母题语言？
- [ ] 动效是否 ≤3 档时长？是否有一个区域在抢戏？
- [ ] 移动端是否重排而不是缩放？
