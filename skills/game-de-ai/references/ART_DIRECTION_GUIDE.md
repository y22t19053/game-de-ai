# ART_DIRECTION_GUIDE — 艺术指导模块

> 目标：把「题材 + 叙事氛围 + 内容结构 + 目标体验」推成**一个可执行的视觉命题**，并给出 2–3 个实质不同的方向让用户拍板。
> 输出物：`ART_DIRECTION.md`（模板见 `templates/ART_DIRECTION.md`）+ `GAME_DNA.md`。

## 1. 输入（缺一项就先去问或去读代码）

| 输入 | 怎么拿 | 缺失时 |
| --- | --- | --- |
| 题材与世界观 | 项目 README / 企划 / 首屏文案 | 问用户一句话概括 |
| 核心循环（玩家反复做什么） | 场景/脚本/说明 | 读入口场景，给出推断让用户确认 |
| 目标体验（想让玩家有什么感觉） | 用户原话 | 给 3 个候选情绪让用户选 |
| 目标平台与尺寸 | 工程配置（Godot 分辨率 / 网页断点） | 默认桌面 1440×900 + 移动 390×844 |
| 现有视觉（已对的 / 想改的） | 截图 + 代码 | 先跑一次 intake，列「不能改」清单 |
| 已认可参考 | `DESIGN_REFERENCE.md` | 无则说明「无认可案例」 |

## 2. 从体验到视觉命题（四步推导）

1. **一句话体验**：玩家在这一屏应该感到什么？（例：「坐在打烊后的馆子里算账，累但踏实」）
2. **视觉隐喻**：什么现实物件能承载这种感受？（例：账本、收据、油渍、钨丝灯、玻璃上的水汽）
3. **三条支撑轴**（必须各写一条，不能含糊）：
   - 色彩策略：主色 hex + 占比 + 一处高饱和 + 暗部色相；
   - 材质策略：2–3 种主导材质（纸/木/金属/布/玻璃/屏幕）+ 磨损方式；
   - 构图策略：网格比例 + 出血/叠压/遮挡手法 + 视线路径。
4. **命题句**：`<隐喻> 的 <材质> 感，用 <色彩> 打 <情绪>，构图偏 <比例/重心>。`
   例：「打烊账本：油渍纸 + 钨丝灯暖橙压住大面积冷灰，重心压在左下 1/3，右上是夜里空荡的玻璃窗。」

## 3. 三案法（必须实质不同）

三个方向必须**在一级轴上不同**，同一套配色换三种说法不算。

| 一级轴 | 选项举例 |
| --- | --- |
| 媒介隐喻 | 印刷品 / 屏幕 / 手写字 / 摄影 / 标本 / 广告牌 |
| 时代与技术感 | 旧报纸 / 霓虹招牌 / 90 年代办公软件 / 未来终端 / 无时代 |
| 情绪温度 | 温暖怀旧 / 冷峻精确 / 荒诞戏谑 / 压抑窒息 |
| 抽象度 | 具象场景 / 符号剪影 / 几何构成 / 纯排版 |

每个方向给一张「方向卡」（写进对话里给用户看，不入档）：

```
【方向 A · 名字】
一句话：<上面的命题句>
参考锚点：<2 个，说明借什么>
色彩：主 <hex> 占 60% / 衬 <hex> 25% / 强调 <hex> 10% / 暗部 <hex 带色相>
字体：标题 <方向>，正文 <方向>，数字 <等宽/非等宽>
构图：<比例> + <一处手法>
材质：<2–3 种> + <磨损方式>
UI 隐喻：<面板像什么>
动效：<一组时长/曲线/编排>
明确不要：<2–3 条，防止滑向模板>
风险：<这个方向最容易翻车的地方，以及怎么兜底>
```

## 4. 决策（留给人）

- 只问 3 个问题，不要一次抛十个：
  1. 哪个最像这个游戏？（身份）
  2. 哪个最不像别的游戏？（差异）
  3. 哪个你愿意陪它做 20 小时？（可持续）
- 给一个推荐项 + 一句理由（「我推荐 B，因为它的材质策略能同时覆盖主菜单和局内 HUD，A 只能用在标题页」）。
- 用户犹豫时，用**并排截图/色板**代替更多文字；仍不定就选「可撤销成本最低」的那个，先做一屏验证。

## 5. 定案后立即产出

1. `GAME_DNA.md`：指纹三件套（专属色 / 字体组合 / 图形母题）+ 三条不可违反。
2. `ART_DIRECTION.md`：命题句、方向卡定稿、色板（hex + 占比 + 用法）、字体规则、材质层叠配方、构图规则、动效基调、**明确不要**清单。
3. 把「明确不要」同步到项目内的 `VISUAL_LANGUAGE.md` 反例区，作为后续实施的裁决依据。

## 6. 自检（交付方向前）

- [ ] 三个方向能否用一句话说清区别？说不出 → 还是一案。
- [ ] 命题句里有没有形容词空转？（「高级」「氛围」→ 换成材质/数值）
- [ ] 色板是否给出占比与用途，而不只是 5 个 hex？
- [ ] 有没有写「明确不要」？没有 → 实施时必然滑回模板。
- [ ] 这个方向换到另一款同题材游戏还成立吗？成立 → 身份不够。
- [ ] 用 25% 缩略图想象这屏，能认出是哪款游戏吗？

## 7. 反例

- 直接给「赛博朋克 / 像素 / 手绘」这种风格菜单 → 得到的是风格的平均值，不是这款游戏的身份。
- 三案其实是同一案的三种配色 → 用户无法做真决策，最后靠感觉挑，返工率最高。
- 跳过「明确不要」 → 实施阶段所有默认值都会回来。
- 把艺术指导写成 2000 字的散文 → 没人会在写 CSS 时读它；必须是可查的规则表。
