# 去 AI 味改写

## 什么时候用

- 用户嫌稿子「太 AI」「太假」「不是我的语气」。
- 要署名的文本：投稿、小红书、社团文案、简介、小说章节。
- 把口述/语音转写整理成第三人称正文。

## 铁律

1. **语料优先于提示词。** 先要 1–3 段用户自己写的同题材文本（旧帖、聊天里的稿、口述转写），只学它的句法与用词，不抄内容。没有语料就先问，不要凭空「模仿文风」——那只会得到模型对「有个性」的平均想象。
2. **把空指令翻成可检查项。** 「高级感 / 氛围感 / 有质感」不算要求。换成具体项：粉色、传统占卜话术、不要剪影、纯几何、留二维码位、标题 ≤20 字。
3. **只改句法，不改立场。** 不加观点、不加转折金句、不把结论说得更漂亮。
4. **保留口语与断句。** 允许不完整句，允许一句只干一件事；长短句交替；不排比、不对仗、不三连。
5. **一次给对照，不给整篇。** 逐句「原句 → 改句」让人挑；整篇重写等于把作者踢出局。

## 自检（逐条打勾，任一不过就返工）

- [ ] 有排比 / 对仗 / 三段式收尾？→ 拆
- [ ] 有没必要的形容词副词（深深、缓缓、不禁、仿佛）？→ 删
- [ ] 有解释情绪的句子（「他感到一阵……」）？→ 换动作或生理反应
- [ ] 同一个意象用了第二次？→ 换或删
- [ ] 有英文装饰、括号补充、破折号金句？→ 删
- [ ] 这段拿掉，剧情或信息有损失吗？→ 没有就删
- [ ] 把一句台词换给另一个角色，读得出来吗？→ 读不出就重写

## 反例

- 用户只说「太 AI 了」→ 改三版全错，因为每次都在猜「AI 味」是什么（152）。
- 让模型「模仿我的风格」但不给文本 → 得到平均化的「有个性」。
