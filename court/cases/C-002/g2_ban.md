# G2 账目禁令纸面表（C-002 裁定 C4 与第七节）

用途：结案报告、台账首行注释、任何纪要出现下列**禁止表述**即违反 C4；必须出现「允许表述」那一列的原句或等价句。
每条都写成可 grep 的字符串，行首带编号，便于核验人逐条定位。

| # | 禁止表述（出现即违反 C4） | 允许表述（须出现或等价） |
|---|---|---|
| 1 | G2 已补足 R1 第 14 条 | G2 读数不构成三案已不同的证据 |
| 2 | G2 覆盖了 R1 第 14 条 | R1 第 14 条所指的「三案是否真不同」仍无 owner、无 test |
| 3 | 3 条记录判同款率达标 | 记录 N 条（N<5）并列留档，待第 5 条后再判同款率 |
| 4 | 3 条记录判同款率超线 | 记录 N 条（N<5）不足以判同款率，本表不作达标或超线结论 |
| 5 | 探针通过即三案不同 | 探针通过只证明「这套制度在开工前被读过一次」，不证明三案不同 |
| 6 | 试点通过即 G2 可以立项 | 试点通过只解除「G2 未被读过」这一条不确定，形态仍待定 |
| 7 | G2 通过等于门禁应上线 | 门禁的再开条件另立：具名 owner + 可跑的七维比例最小 test + 三字段护栏，三者齐备后另开新案 |
| 8 | 记录齐全说明设计有效 | 记录齐全只说明台账可核验，不说明设计有效 |
| 9 | 盲配成功说明三案有差异 | 盲配成功说明该作存在可核验的内部同质信号，不构成三案已不同的证据 |
| 10 | 本轮 G2 白跑，说明三案相同 | 本轮读数缺失说明机制未出数，不等于三案相同 |

## 复核用 grep 清单（核验人执行）

注意：本表自身的「禁止表述」列**按设计**包含这些字串，因此清单只扫**结案报告与台账注释**，不要把本文件放进 glob。

```
# 1) 结案报告不得出现已补足/覆盖 R1 第 14 条（命中即违规）
grep -n "已补足\|覆盖.*R1 第 14" docs/CASE_REPORT_C002.md cases/C-002/g2_ledger.jsonl

# 2) 结案报告与台账不得出现同款率达标/超线结论（命中即违规）
grep -n "同款率.*达标\|同款率.*超线" docs/CASE_REPORT_C002.md cases/C-002/g2_ledger.jsonl

# 3) 结案报告不得出现「探针通过即三案不同」（命中即违规）
grep -n "探针通过即三案不同" docs/CASE_REPORT_C002.md

# 4) 必须能 grep 到否证句（找不到即违规）
grep -n "G2 读数不构成三案已不同的证据" docs/CASE_REPORT_C002.md cases/C-002/g2_ledger.jsonl
```

判定口径：第 1/2/3 条有命中即违规；第 4 条必须至少命中一次。
