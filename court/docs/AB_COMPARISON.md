# 新旧流程成本与效果对照（A / B / C）

本文件回答任务书的硬要求：**不能用架构报告自证制度有效**。所以这里只写实际发生过的事，并把「代理指标」与「实测」分开标。

## 〇、三组是什么

| 组 | 流程 | 本案状态 |
|---|---|---|
| **A** | V0.3 旧七轮：R1 攻击 → R2/R4/R5/R6 攻击 → R3 五专业 → R7 重建，4 个 fresh 子代理各自读同一份报告与提案 | **已跑过**（对象是《GAME DE-AI》整体架构，非单一提案） |
| **B** | 新法庭：登记案件 → 6 条证据 → 控辩书状（2 个 fresh）→ 形成争议点 → 3 轮交叉询问 → 5 位隔离陪审 → 独立法官裁决 → 考成派单 | **已跑**（C-001，bistro-rush 闭合文法试点） |
| **C** | 混合：普通案走轻量法庭（1 控辩 + 1 轮质询 + 3 陪审）；重大争议才调七轮 | **未跑**（本轮没有时间跑第三组，见 §五） |

## 一、规模与成本（代理指标，非 token 账单）

**先说清楚：本轮没做 token 插桩，下面全部是代理量，不能当账单用。**

| 代理指标 | A 七轮 | B 法庭 |
|---|---|---|
| 子代理数 | 4 | 8（控 1、辩 1、陪审 5、法官 1） |
| 子代理输出字符量 | ≈122.5 KB（r1 24.8K / r2456 44.4K / r3 15.1K / r7 38.2K） | ≈40.7 KB（控 3.4K、辩 2.9K、五票 15.1K、裁决 17.8K、质询回答 1.7K） |
| 人工（lead）操作步数 | ≈15（派工、读回、改稿三轮） | ≈45（登记 6 条证据、2 份书状、1 争议点、3 轮质询、5 票、1 裁决、3 任务、核销） |
| 墙钟时间 | ≈25 分钟 | ≈35 分钟（含陪审并行）＋结项文书 |
| 一次性工程成本 | 0（纯提示词） | ≈430 行引擎 + 154 行 CLI + 10 个测试 + 16 次红队脚本 |

**读法**：B 的**单案运行成本**并没有更低，反而因为多 4 个子代理与更多人工作业更贵；B 唯一明显省下来的是**返工**（见下）。一次性工程成本 2 天量级，需要多案摊薄才划算——这一点必须如实写，不能拿「制度更严谨」当收益糊过去。

## 二、效果对照（八个指标）

| 指标 | A 七轮 | B 法庭 | 说明 |
|---|---|---|---|
| 重大缺陷发现率 | 高：14 条攻击，其中 4 条迫使我撤回自己的数字（74 组重复 / 32 字复制 / 847 色当病 / Delta 分离度） | 中高：9 条 findings，核心一条是**逼辩方自认**「闸门只判有无声明、不判多寡」→ 直接改写裁决为 pilot | A 强在覆盖率，B 强在**把自认变成可引用的卷面事实** |
| 误判率 | 有：r2456 自身两条结论被推翻（CSS 混入语料、containment 判据），七轮里 2.5/7 轮未产生新信息 | 低（就本案）：五票无一被法官驳回，裁决未出现需要 remanded 的情形 | 样本都是 n=1，不能外推 |
| 证据完整性 | 弱：七轮产出是自由文本，没有证据编号，「74 组」这类数字事后无法追溯口径 | 强：6 条证据带来源/版本/类型/可信度/是否独立验证；裁决 9 条 findings 全部挂 E001–E006，引擎拒绝悬空引用（A5 实测） | B 的核心优势 |
| 裁决稳定性 | 无稳定机制：同一问题跨轮重复计数的风险靠自觉 | 中：五票全部 conditional 且理由高度重叠 → 结论稳定，但**代价是独立性可能不足**（见 OPEN_ISSUES I-06） | 稳定性高不等于独立性好 |
| 执行兑现率 | 低：七轮结论落到「建议」，无派单、无验收、无逾期概念 | 高：3 项任务、明确 deadline 与 acceptance，验收须第三方且不得自验（引擎强制 `SELF_VERIFICATION`） | 这是考成法带来的真实差别 |
| 人工介入时间 | 少（读回 + 归并） | 多（CLI 操作 45 步） | B 更贵 |
| 维护成本 | 近似 0 | 引擎 + CLI + 测试 + 红队脚本，改动需同步文档 | B 更贵 |
| 返工 | 高：本轮三次改口径（74→逐对裁决表、B.12 降级、F.3 判淘汰） | 低：一裁终局，条件写成可验收项后不需要来回 | B 的核心收益 |

## 三、各自抓到了对方漏掉的东西

- **只有 A 抓到**：`r2456` 用「同一套指标量已验收的小泽定稿」做**反证实验**（28.23 > 23.43）——法庭没有让任何人做这个实验，因为法官只能引用已登记证据，而提案方不会主动提交证伪自己的实验。
- **只有 B 抓到**：把「闸门只提供溯源力、不提供收敛力」这句话变成**辩方在质询中自认的卷面事实**，并据此把裁决从「批准试点」收到「pilot 只批审计」。A 组当年也怀疑过 G1，但没有形成可执行的裁决。
- **两组都漏**：都没验证「≤7 条禁令能否承载身份」——这正是 C-001 裁决里被列为第一条件（C1）的原因。

## 四、结论（含不支持的部分）

1. **不支持「法庭全面优于七轮」**：单案成本更高、人工更多、陪审同质。
2. **不支持「七轮该废除」**：反证实验是 A 组独有的能力，法庭结构天然不鼓励提案方自证其伪。
3. **支持「结构互补」**：法庭给的是**可引用的证据 + 可执行的裁决 + 追责闭环**；七轮给的是**主动构造反例的能力**。
4. **C 组（混合）在当前证据下是唯一站得住的方案**，但它**尚未被跑过**，因此不能写成「已验证」。
5. 如果只能选一个：**普通工程决策选 B，重大架构判断必须 B + 一次 R4 级反证实验。**

## 五、没有做的事（如实记录）

- C 组未跑：本轮工时已用于原型与案例，没有第三个案例。要验证混合流程，需另立一案（建议用「G2 门禁还是探针」或「G4 门下省 τ 校准」）。
- Token 未插桩：所有成本都是代理量。
- 未做多模型对照：`docs/DESIGN.md` 明确要求调查「不同模型/提示策略能否提供真实独立性」，本轮**没有做**，只有同模型隔离上下文。
- 样本量 n=1：任何「提高质量」的表述都只对 C-001 成立。

## 六、采用判定（阶段 5 结论）

按任务书五档：正式采用 / 修改后试点 / 保留混合 / 推翻回退。

**判定：修改后试点（不是正式采用）。**

理由（可被反驳）：
1. 法庭的**真实增益只有三处被证实**：证据可追溯（6 条证据 + 9 findings 全部挂编号）、裁决可执行（3 任务派单 + 独立核销）、执行者被第三方抓到错（1 次，clamp 重复计数 29.3%→28.7%）。
2. **成本没降**：单案人工操作 45 步、子代理 8 个；一次性工程 2 天量级。只有多案摊薄才可能划算，本轮无法证明。
3. **独立性没被证明**：五票全 conditional 且理由重叠，`OPEN_ISSUES` I-06 明写「同模型不等于独立」。
4. C 组（混合）在逻辑上最合理，但**没跑过**，不能算采用。

生效条件（满足才算试点成功）：
- 再跑 2 个案件（建议一案=G2 门禁/探针，一案=high 案以验证七轮接线）；
- 两案合计人工操作 ≤60 步；
- 至少出现一次「陪审意见与法官裁决方向不同」；
- 至少一次 `reconsider`（发回重审）被真实使用。

不满足则降级：保留「证据登记 + 考成核销」两个模块，撤掉陪审与七轮接线，回退为轻量审查。
