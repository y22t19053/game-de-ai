# C-003 提案：《午夜餐厅》界面模板化改造的两条路线

作者：lead（提案方）｜提议开庭类型：major｜日期：2026-11-15

## 一、问题

`bistro-rush` 是 React + Phaser 的手机优先时间管理页游。它的**配色有身份**（奶油 `#fff5e3`、珊瑚 `#f26b3a`、金 `#f4b942`、硬影 `0 8px 0`），但**结构没有身份**：47 种圆角、30 种字号（10px 出现 55 次、9px 36 次、8px 25 次）、17 种间距（含 1/3/5px）、统一 22px 圆角卡片 + 硬投影。任何一款休闲页游都能套上这套骨架。

W1 之后它是我们的真实改进对象；V0.2.0 需要先定方向，否则后面的改动会各改各的。

## 二、两条路线

### 路线 A：保留，只做层级与材质（保守）

- 色板与"奶油+珊瑚"完全不换；圆角收敛成 2 档（卡片 22px / 小控件 10px）；字号收敛成 5 档（10→14 起）；间距统一到 4pt 刻度。
- 把 `box-shadow: 0 8px 0` 的硬影从"全站投影"改成**只给可点击物**，并加一层 1px 内侧亮线（压痕感）。
- 收益：一天内可完成，风险低，玩家无感但截图对比更整。
- 代价：**结构问题不解决**——"卡片墙 + 圆角 + 硬影"这套语言仍然存在，只是数量变少。

### 路线 B：换成后厨/出单纸语言（激进）

- 底色改冷白 `#f4f1ea` + 不锈钢灰 `#8d9499`，珊瑚降为"辣椒红"点缀（只用于警示与按钮）；圆角归零（0/2px），阴影改成 1.5px 硬边 + 纸胶带式斜贴。
- 组件语言：菜单卡 → **出单纸**（打孔边 + 厨房手写体 + 项号右对齐）；按钮 → **压杆式**（上下 1px 金属边）；状态条 → **冰箱温度贴**。
- 收益：结构层就换了——从"卡片应用"变成"后厨收银台"，与小泽的"档案纸"彻底分家。
- 代价：约 3–4 天；需要重做 3 个核心屏；**有过度设计风险**，且用户没看过 B 的实拍。

## 三、已确认的约束

- 不改玩法、数值、关卡数据（C-003 只谈视觉）。
- 不得为了"统一指标"机械加 token（用户原话）。
- 任何正式版改动需用户确认；本提案只授权在 `bistro-rush/visual/` 下做原型。
- 判断"更像游戏"的标准不能被"字号种类下降"替代（E003 已证：把小泽已验收定稿判得更差）。

## 四、失败判据（提案自设）

- 若在 1440×900 与 390×844 两档下，改造后首页截图**不能**让 3 位独立评审在 25% 缩略图里把它与小泽/浮生牌区分开 → 判为"没换骨"，路线 B 失败。
- 若改造导致任一核心屏的可点击物 ≤ 40px 或对比度 < 4.5:1 → 立即回退。
- 若 3–4 天窗口内做不完 3 个核心屏 → 收缩到 1 个屏，不得延期。

## 五、请法庭解决的分歧

1. 该走 A、B、还是"A 的一部分 + B 的一部分"？
2. "结构与身份"的验收标准应该是什么（不许是字号/颜色计数）？
3. 是否值得为它花 3–4 天，还是先做更小的事（例如只改首页 + 结算屏）？
