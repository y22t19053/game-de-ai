# 轻量分流实测报告（V0.2.0）

## 一、结论先写

| 项 | 结果 |
|---|---|
| 普通创作是否真能不开庭 | **能**：3 项全部走完「提案 → 门下省日常审核 → 退回/修改」，**0 次开庭、0 次证据编号、0 次陪审** |
| 审核是否真拦住了东西 | **是**：3 项全部退回，其中 1 项被判定**误分类**（应并入 C-003） |
| 误分流 | **1 次**（ORD-02 实为 C-003 争点的一片切片） |
| 出错位置 | **全部出在提案人（我）的事实层面**：行号、数值、"保留现值"、断点、几段结构——不是判据层面 |

这一点值得单独记住：**普通路径的价值不是"少走程序"，而是让一个非提案人用源码把提案里的事实逐条打回**。三项里没有一项是因为"想法不好"被退回，全是因为**我引错了行、算错了数、写错了前提**。

## 二、三项的实际运行记录

### ORD-01《浮生牌》分享码 toast 文案订正 —— 退回（不需开庭）

- 分流理由：纯文案、副本内可逆、无分歧 → 普通路径。判断人：提案人自判。
- 门下省实测取证：真目标行是 `src/texts/texts-main.js:37` `toastImportFail: '分享码无效或已过期',`，**原文本来就没有句末句号**，我提案里的"去掉句号"前提不存在。
- 我另外三处错：①"全库无句号"为假——`src/ui.js:130` 的 `toast('今日已抽牌多次，注意休息。', …)` 带句号；②字数 9→11 我写成 12；③`copy_scan.py --type toast` 在本机不存在（该脚本只在技能目录里，未拷到工作区），验收项不可执行。
- 处理：按退回要求重写——先定标的（分享码串 vs 日运串二选一），删掉"全库无句号"断言，行号与字数按实测，预算改 40 字并注明出处。**未改任何源码。**

### ORD-02《午夜餐厅》圆角 47→2 —— 退回 + ESCALATE 并入 C-003

- 分流理由（我的）：可逆、同一设计语言内整理 → 普通路径。
- 门下省判定：**命中判据②实质分歧**——它正是 C-003 正在审的"圆角收敛路线 A"的一片切片；在裁决前把它做成执行方案，等于**裁决未出而结论先落地**。另命中判据①（197 条声明、全站视觉）。
- 取证纠正：`22px` 在 `bistro-rush/src/ui/styles.css` 的 197 条 `border-radius` 里**出现 0 次**——我写的"卡片 22px，保留现值"是错的，22px 是新引入值；此外 47 个值里有 14 条多值简写、4 条椭圆百分比、9 处 `inherit`，"收敛到 2 档"实际是重写 197 条声明。
- 处理：**ESCALATE**，`ROUNDING_PLAN.md` 暂缓，草稿仅作 C-003 内材料；并明确记录这条错误同时污染了 C-003 提案（"统一 22px 卡片"同源）——由 C-003 裁决时并行订正。

### ORD-03《小泽模拟器》移动端页脚换行 —— 退回（不需开庭）

- 分流理由：只出方案、副本内、可逆 → 普通路径。
- 门下省取证纠正三处：①原型 `.dossier__foot`（`visual/prototype/styles.css:466-475`）是 `display:flex; justify-content:space-between`，**没有 gap**，我引的 8px 来自 `.masthead`（`:862`）；②原型断点是 `@media (max-width: 900px)`（`:845`），**没有 899px**；③"正式版同结构"为假——正式版 `index.html:132-136` 的 `.v2-menu-foot` 是**三个** span，且 `css/v2.css:569` 已是 `flex-wrap: wrap; gap: 6px 18px`，本就能换行。真正的问题是"三段在 390 宽怎么折、第三段要不要留"。
- 处理：按三段结构重写，断点统一用 900px，并标注与 C-004 清单 A#1 同源。

## 三、成本

| 项 | 模型调用（估） | 人工 |
|---|---|---|
| 3 项普通创作（含 1 次门下省审核） | 1 次审核调用 + 3 次提案执行，约 2–4 万 input | 约 25 分钟（含读源码核对） |
| 对照：一次 major（C-002 口径） | 80 次调用 / 8.7 万 input / 3.9 万 output | 约 95 分钟 |

→ 普通路径约为一次 major 的 **1/5 token、1/4 人工**；且**没有陪审与书状**。

## 四、差点误分流 / 本报告要承认的两件事

1. **ORD-02 是我判错的**：我用"可逆"当理由，忽略了它属于一个**正在审的设计争点**。已按门下省意见回流。
2. **三项退回全部源于我写提案时凭记忆编数字**（行号、22px、8px、899px、12 字）。这说明普通路径的真正闸门不是"审得严"，而是**审核人必须真的去读源码**；把审核做成"读一遍提案点个头"，轻量路径会立刻退化成盖章。
