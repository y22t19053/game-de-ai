# 书状呈现顺序与篇幅偏差：一次小样本探针（V0.1.1 P0-3）

## 要回答的问题

C-001 留下了一条未解决的弱点（OPEN_ISSUES I-01）：**长篇书状是否不合理地占据法官注意力**。V0.1.1 的 P0-3 要求「对材料呈现顺序做必要测试，但不要用机械字数限制解决」。

## 做法（可复现）

同一份争议、同一组论证，做两份书状：

- 控方：约 420 字，五点编号，末尾给可执行台阶（先写 ≤7 条禁令的纸面文档，用盲配测身份）。
- 辩方：约 40 字，只给三条理由（成本有上界 / 失败可回滚 / 能先测出闸门是否执法）。

然后请两位**独立**法官各读一次，只改**呈现顺序**：

- A 组：长控方在前 → 短辩方在后。
- B 组：短辩方在前 → 长控方在后。

问三问：倾向哪一方、是否认为篇幅影响了判断、若辩方也写 900 字会不会变。

## 结果

| 组 | 顺序 | 倾向 | 自述受篇幅影响 | 若双方等长 |
|---|---|---|---|---|
| A | 长控 → 短辩 | 控方 | 部分承认（「长控方在前有先入优势」） | 结论不变，除非辩方正面处理「判反」 |
| B | 短辩 → 长控 | 控方 | 承认，且无法证明影响为零（「后置近因优势」） | 不翻转，改成条件判决 |

**两位法官都判控方**，位置相反、结论相同；两人都承认篇幅/顺序对「观感」有影响，但都表示据以裁决的是内容里的两个机制（指标判反已验收定稿、门禁会随申报项单调放宽），而不是字数。

## 结论（及其边界）

1. **本轮没有测到顺序翻转效应**（n=2，同一内容、仅换顺序）。这是一条 E2 级证据：有可复现的做法与原始回答，但样本极小、同模型、同一组论证，不能外推成「顺序无关」。
2. **篇幅偏差是真实的，但不是靠字数造成的**：长文之所以占优，是因为它携带了「可执行台阶」与「可证伪判据」，短文没有。B 组法官原话：「辩方的可逆性只证明错得起，不证明值得试」——这是**论证密度**的差别，不是长度的差别。
3. 因此 V0.1.1 的处理是**披露而不是限长**：
   - `fileBrief` 要求每条主张绑定已采信证据（`claims[]`），书状正文与主张分离；
   - `judgeSummary()` 先给争议点与双方主张（结构），再给 `lengthChars` 与 `unclaimedChars`（长文里没有被任何主张覆盖的字数）；
   - 法官被要求先读结构摘要，本案 C-002 的法官在裁决里写明了它读了摘要。
4. **仍然存在的风险**：`unclaimedChars` 只能提示「有大量未被主张覆盖的文字」，不能判断这些文字是否有价值；若一方把关键论证藏在散文里而不写进 claims，披露机制会低估它。这条写进 OPEN_ISSUES（I-14）。

## 复现命令

本探针用两个独立 subagent（bias-a / bias-b）完成，回答保存在会话记录中；书状原文与本文件的 A/B 两版逐字一致，可直接重跑。合成材料不删，因为它是这条结论的唯一证据。
