## ② 三处最模板化的结构

**②-1 样式靠复制粘贴传播，而不是靠尺度** — `styles.css:851`、`:1390`、`:1625`、`:1683`、`:1811`、`:2397`
六处声明体逐字相同：`font-size:10px;font-weight:700;color:var(--ink-faint)`；`styles.css:3832`、`:6555` 是同款加 `display:block` 的第八、第九份。八处分别是关卡侧栏小字、设备名、托盘头、托盘空态、装配空态、弹窗页脚、主厨格位、主厨属性——**语义八竿子打不着，样式一模一样**。为什么算模板化：改"次要说明文字"这一层时，你得先在 8 个选择器里逐个判断它属不属于这一层，而样式表本身不提供这个判断；于是下一次仍然靠复制。

**②-2 五个屏各自手写同一套 header** — `Levels.tsx:25`、`Restaurants.tsx:16`、`Upgrades.tsx:55`（都是 `<header className="screen-head">` → round-btn 返回 + eyebrow + h2 + `<div className="head-stats">`）；`Modes.tsx:32`、`PlacementReport.tsx:26`（同一解剖换名 `mode-head`，右侧改 `mode-rank`）
为什么算模板化：一条版式规则被抄五份，规则就没有单点。漂移已经发生——普通屏用 `head-stats`，模式屏外面多包一层 `mode-rank`，同一个"标题基线"由两套 CSS 决定，改一处必漏四处。

**②-3 同一个数字四处各写一遍** — 星数上限：`Title.tsx:102` 写死 `{36 * 3}`、`Modes.tsx:95` 写死 `/ 108 星`、`Levels.tsx:36` 重算 `levels.length * 3`、`Restaurants.tsx:77` 走 `restaurantProgress()`（`store.ts:496` 里同样是 `const max = levels.length * 3`）；「定级不跳过内容」也在 `Modes.tsx:105`、`PlacementReport.tsx:76`、`Upgrades.tsx:152` 各说一遍
为什么算模板化：这不是四个视图，是四份实现，其中两处是写死的魔法数——加第 37 关时它们会静默变成谎话。同类错误已经发生：`Restaurants.tsx:73` 把"每店 8 关"写成除数 `Math.ceil(progress.stars / 8)`，但 `levels.ts:744-828` 的 night 只有 4 关（index 1..4；全库 36 关 = 8+8+8+8+4），night 满星 12 星时 `ceil(12/8)=2`，配合 `Stars.tsx:12` 固定渲染 3 颗星，**第 3 颗永远点不亮**；同屏 `Restaurants.tsx:86` 还写着「每家餐厅 8 个关卡」。

## ③ 三处 AI 味文案（原句 → 改法 → 为什么不是换同义词）

> 前置：`Title.tsx:63`「城市睡了…」已在 VOICE_BIBLE §7 列为禁用，`achievements.ts` 止损线已被评为"本作最高标准"（§6），`recipes.ts:21`「招牌中的招牌」已裁定——这三处**不在本文重判**。以下三条是 COPY_DIFF v3（14 条）**未覆盖**的。篇幅比按项目口径（汉字+数字+拉丁字母，∈[0.80,1.25]）先行算过。

**③-1 `modes.ts:159`** 原句：`动态难度、经营报告、同种子比较。`
改法：`压力每 40 秒涨一档，同种子比排名。`（13→15，1.15）
为什么不是换同义词：病根是"把三个内部特性名词并列"——`动态难度`是开发分类，不是玩家在屏幕上遇到的任何东西；把词换成「自适应挑战」「结算数据」更漂亮，但仍是点单：三个名词、零动词，读者拿不到可预期的事。改法只做一件事：把同文件 `modes.ts:101` 已写明的真实机制（压力每 40 秒升一档）提到"功能清单"的位置上，`同种子` 也是本文件既定词（`modes.ts:152`、`:166`）。数字与机制都是既有的，没有新增事实。

**③-2 `recipes.ts:606`** 原句：`寿司散了也要吃完；及时止损也是一种止损。`
改法：`米饭铺平，三文鱼盖满，散着端上去也算一道。`（18→19，1.06）
为什么不是换同义词：原句是循环定义（"止损也是一种止损"）外加一条跟自己对立的要求（"也要吃完"/"及时止损"）；换成「放弃也是一种选择」只是把口号换个牌子。菜品文案按 VOICE_BIBLE §5 要"写结构、写操作要求"——这道菜的真实结构就是米饭 + 三文鱼 + 海苔的装配菜，改法写的正是它的三步装配与结果。读者拿到的是操作，不是一句能印在杯垫上的话。

**③-3 `achievements.ts:36`** 原句：`两包苏打饼干配热牛奶，夜班人的正餐。点过夜班固定套餐的人都懂。`
改法：`两包苏打饼干配热牛奶，夜班人的正餐。端满二十份，这份也算。`（27→24，0.89）
为什么不是换同义词：病根有两层，换词都治不了。一是"…的人都懂"借一个人群替读者确认感受（假共鸣），换成「你懂的」「不用多说」是同一装置换零件。二是**事实错位**：该成就条件是 `dishesServed >= 20`（端出 20 份菜），与"夜班固定套餐"无关。前半句是 §6 已认可句，保留不动；只把后半句换成成就真正记录的事，顺带解答玩家"夜宵算不算一份"的疑问。
