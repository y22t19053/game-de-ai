# ORD-03《小泽模拟器》移动端页脚换行方案

- 类型：普通创作｜路径：轻量（不开庭）
- 提议人：lead｜审核：门下省日常审核｜执行：lead｜截止：2026-11-17

## 改什么（只出方案，不改正式版）

现状（V0.1 原型副本 `little-zelensky-simulator/visual/prototype/styles.css`，正式版同结构）：390×844 下菜单屏页脚两段——

`2022.02.24 — 04.02`（左）与 `38 天 · 时间由你推进`（右）——中间只有 8px 间隙，缩略图里糊成一行（`visual/preview/menu-390x844.png` 可见）。

方案：移动端断点（`max-width: 899px`）下改为**上下两行**，左段在上、右段在下，`gap: 6px`；桌面端保持单行。

## 为什么

- 这两段是不同性质的信息（日期/时长 vs 承诺句），挤一行会被读成一句话。
- 只移动端生效，桌面端零变化，回退成本 = 删一条 media query。

## 不做什么

- 不动印章、不动标题、不换纸色。
- 不改正式版：方案写入 `little-zelensky-simulator/visual/v020/MOBILE_FOOTER.md`，实施需用户确认后进副本。

## 验收

- 390×844 重截：两段不重叠、不超出纸面、`content.width = 390`（无横向溢出）。
- 1440×900 重截：与现状 `sha256` 一致（或像素差 0）。
- 门下省审核通过即核销。

## 判据（为什么不开庭）

可逆、无实质分歧（纯排版订正）、无资源问题。若审核认为「页脚信息该重构」则 `ESCALATE` 并入 C-004。
